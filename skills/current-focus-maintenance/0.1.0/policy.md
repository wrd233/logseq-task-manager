# Current Focus Maintenance 0.1.0

The skill may propose exactly one nullable `currentFocus` field update on one existing WorkObject. It must use frozen Evidence, preserve identity, title, lifecycle, engagement, ownership, and natural Logseq source text, and decline ambiguous, waiting, lifecycle, rename, completion, cancellation, or scope-expanding requests. The Kernel alone authorizes and commits a proposal after rechecking target version, managed projection, Evidence SHA-256, Skill identity, LOW risk, and recovery state.
