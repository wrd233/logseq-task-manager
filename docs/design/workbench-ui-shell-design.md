# 工作级界面与就近引导

实现基线：`8529212296f0b65fb78ef7ccd2a2102474d9310a`，分支 `codex/workbench-ui-shell`。本设计对应真实插件的实现；报告、材料和审阅继续使用基线模块。

## 日常路径

在 Logseq 选中工作标题或正文块，通过宿主「打开工作台」或「工作台 → 打开当前块的工作」进入。后者寻找最近的真实工作对象。普通原生子块点击默认不切换当前工作；自动跟随是工作选项中的显式选择。

工作名称从来源对象派生，MiniProject／事务／任务／Project／Area 保留对象含义。显示时去掉名称里的对象标记和 Markdown 强调，原文不改。单行对象根标题由带 sourceId/contentVersion 的工作标题呈现，正文不再重复；多行根正文、原结构和历史完整保留。

正文默认是基线的完整报告排版，不读取旧的个人折叠作为首次报告状态。正文与材料是当前工作的两个主入口。「在 Logseq 写作」调用既有原生宿主端口，进行中的输入显示「继续原生输入」。插件没有正文编辑副本。

材料切换保持同一 Graph/root。打开材料文件后，「正文」恢复报告模式、范围、选定块、焦点和阅读位置。另选工作才清除旧书签。材料草稿、写入冲突和引用部分成功仍由材料模块处理。

审阅与历史放在内容入口右侧。存在待审阅变化时显示「有改动 · 进入审阅」。正常阅读隐藏阶段工具条和变化叠层；进入后复用原阶段界面。收起审阅不能丢弃正在输入的审阅草稿。历史显示明确只读事实。认可快捷键在未进入审阅时只展开入口，不能直接认可用户没看的版本。

## 入口迁移

| 基线常驻入口 | 当前位置／用途 |
| --- | --- |
| 工作视图、材料、正式任务等全局模块按钮 | 顶部「工作台」菜单；包括明确切换工作、全部材料、正式任务和设置 |
| 报告／原结构模式按钮 | 工作选项「查看原结构」；正文默认报告 |
| 聚焦范围、刷新、自动跟随和上层工作 | 工作选项中的阅读动作，附一行说明 |
| 绑定／打开／重绑工作目录 | 工作选项「工作目录」分组 |
| 允许连接、结构整理、停止连接和写回恢复 | 工作选项「外部连接与恢复」分组；保持各自许可和原结果查询 |
| 阶段记录、提交、认可、历史和成果 | 按需「审阅与历史」；复用原模块 |
| 材料页重复返回和关闭 | 当前工作 shell 的「正文」与全局关闭；独立材料库仍保留原返回 |
| 连接技术状态 | 材料「目录与查找」详情；连接就绪不表示 agent 正在工作 |

## 引导与视觉

没有工作时只显示选择原生工作块的短引导与真实动作。材料空态、导入后未插引用、草稿恢复继续使用材料模块现有事实。正常全文没有教程墙、内部版本、scope、JSON 或目录参数。必要时工作标题下显示未结束原生输入、历史只读、来源过期、审阅问题或操作失败；收窄范围才显示范围计数。

整体只有顶层入口、工作身份与写作动作、正文／材料这一组导航。14px 正文与原模块自然段排版保持，依靠去掉冗余入口和空行提高密度。颜色复制宿主的限定主题变量，仅用于插件 iframe；不修改 Logseq 原生正文样式。

菜单支持鼠标、Tab、Escape、外部点击关闭和焦点返回。中文组合输入及文本输入中的 Escape 留给原模块；来源刷新不替换未变化的菜单控制。长篇正文中的链接和文本选择仍由原 renderer 管理。
