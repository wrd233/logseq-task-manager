# 情境化工作阅读渲染

2026-11-19，承接 `codex/contextual-work-briefing`（`bb44afe`）的自然语言简报、事实/推断/建议语义、真实来源关联及陈旧提示，整合到 Logseq 日常工作台，取代另一个独立简报弹层作为主要读法。

| 层次 | 模型负责 | 阅读器负责 |
| --- | --- | --- |
| 顶层 | 根据意图和工作复杂度组织一句话、段落或简报 | 轻量正文、可辨识的展开动作；不过多固定栏位 |
| 描述 | 保留思路、历史、条件、反例、限制和不确定性，决定分组与强调 | 就近展开、多单元同时打开、轻量缩进；语义键恢复展开及焦点 |
| 证据 | 指向实际 sourceId/materialId，建议展示形式 | 版本、原文、父级上下文、真实数据表/小图及材料入口；与当前版本对照 |

阅读器不把 AI 摘要当作原始记录。没有完整历史依据时显示缺失；变化单元提示核对，仍可打开当时依据，不自动更新旧结论。新增及未归入描述的来源以真实原文补充。复杂表、图或文件通过原有材料/原文入口查看，返回不丢失阅读现场。

Logseq 为主要阅读体验：正文和小字号证据形成层次，克制的关注色和变化提示具备文字/键盘可辨识性，随主题、栏宽变化。DSH 使用同一方案的折叠简报与已有原文视图，在协作场景按需查看；没有新一套模型协议。

实现入口：`briefing-model.ts`、`progressive-reader.ts`、`source-table.ts`、`report-style.ts`（Logseq）；`work-experience/workbench.jsx`（DSH）；契约与完整交互见 [reading-plan-contract](reading-plan-contract.md) 与 [渐进式工作台](progressive-workspace.md)。
