# 工作台视觉与原文阅读升级

2026-10-06。基于最新材料抽屉与一键阅读，改造当前插件，不建立第二份正文。

## 可交互参考

打开 [统一视觉稿](../implementation/assets/workbench-visual-refresh/interactive-design.html)，切换明暗、窄宽、正文／材料、菜单、行内改名、目录、收纳和失败状态。全文使用 [102 块合成样例](../../apps/logseq-plugin/tests/fixtures/visual-refresh.ts)：四层、两个事务、一个子 MiniProject、重复句、多行内容、代码、引文、表格、材料别名及未知标记。视觉稿仅为可操作参考；最终 Desktop 证据另列。

## 外壳与阅读

暖灰工作身份区、阅读表面与补充信息区，用低饱和青绿色表达主要动作、选中和焦点。深色主题使用相同信息层次。紧凑身份区保留名称、对象类型和原生写作入口，下方一行正文／材料与按需审阅。长名称换行，菜单不占据名称空间。正式任务、设置及外部连接继续在原工作台／工作选项中。

正文连续呈现，不给每个块新增卡片。四层缩进仍保留所属关系；目标、思考、问题、记录提供局部标题，说明使用浅底与细边。普通状态不铺满颜色，问题标题不会变成警告或待办。代码与表格局部滚动，正文和长文件名换行。

## 显示投影

只识别真实块第一条正文行的有限行首语法，支持成对粗体：目标 → 目标、想法 → 思考、注／说明 → 说明、记录 → 记录、问题 → 问题。TODO 等宿主任务标记作为文字状态保留；事务／任务／MiniProject 显示类型、状态和完整名称。普通 TODO 不升级为对象。保留 hashtag。

只隐藏识别到的前缀及其空白分隔符，完整后续句子、多行和子树保留。代码、引文、行内代码、未知标记、句中标记、残缺粗体和标记形式的 Markdown 链接均按原样渲染。同类连续兄弟在同一局部上下文共享标题；无标记段、对象或其他类别打断。已证明安全的 composer 分组边界保持，其他位置保持原顺序。

隐藏标记是展示事实，有 raw 偏移映射。版本、历史、认可与写入仍绑定原内容。单行根对象由映射到真实来源的工作名称承载，不重复全文标题；多行根正文继续完整显示。历史仍显示当时保存内容及原有只读保护。条目菜单的“对照原文”和工作选项的“查看原结构”保留核对入口。

## 材料与展开状态

文件名为阅读入口，类型、只读、失联、草稿为次级信息。“更多”是依附入口的覆盖菜单，开闭不改变列表尺寸；超出窄窗或底部时调整位置，滚动时跟随有效入口。复制在真实成功后于固定的行内反馈位置显示“已复制”；失败显示重试。文件改名直接编辑该行，错误保留草稿。其他明确决定使用共享对话框。

目录页显示可辨认名称与默认保存位置，完整路径按需展开。“添加目录”仍调用宿主选择器。默认位置只作用于新材料，解除关联不删文件。空列表保留明确拖入说明；有内容时收紧提示，拖入时突出落点。

原生长文收纳复用同一套主题、输入、错误和主次动作，保留原生粘贴、阈值、命名和精确范围保护。保存后的补插／复制入口、部分成功、只读、冲突和草稿恢复沿既有服务实现。

## 键盘与生命周期

Tab 可达、焦点可见；普通菜单 Escape 关闭并返回有效入口，外部点击关闭。输入和组合输入的 Escape 不被菜单处理。模态对话框由浏览器管理焦点范围；普通菜单不锁焦点。范围切换释放菜单与本轮表单，晚到 IO 不覆盖新工作。宿主收纳样式限定到自身对话框，卸载后移除。
