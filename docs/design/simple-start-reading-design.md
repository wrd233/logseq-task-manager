## 最短路径

安装并启用插件，照常在 Logseq 写事务或 MiniProject，点标题旁一直可见的「阅读」。已保存的根块及全部子块立即组成完整报告。基础阅读必填设置为 **0 项**，进入已显示对象为 **1 次点击**，阅读不改原文、不补属性，也不授予正式任务或 agent 权限。

新 profile 默认开启工作阅读和材料，正式任务默认关闭。已有用户显式关闭阅读或材料的设置继续有效；已有正式任务和连接配置保留。首次进入仍是原生页面，插件不自动导航或遮挡正文；有有效的上次阅读现场时才恢复面板。

## 入口和范围

| 入口 | 范围 |
| --- | --- |
| 事务／任务标题旁「阅读」 | 该块及全部子树 |
| MiniProject 标题旁「阅读」 | 该块及全部子树；不要求重复 `#MiniProject` |
| 内嵌事务「阅读」 | 明确切到该事务，正文／材料栏提供「返回：所属 MiniProject 名称」 |
| Project／Area 页面标题旁「阅读」 | 当前真实页面的全部实际正文块 |
| 顶部「工作台」 | 原生焦点所属工作；Project／Area 当前页面；无工作时显示具名「继续阅读」供明确选择 |
| 普通块右键／快捷键 | 真实选择的普通块及子树，保留普通正文阅读能力 |

普通段落点击、选字、链接和输入不会改变当前阅读范围。顶部入口不会根据 SDK 的最近编辑块猜工作。代码、引文和普通 TODO 不获得工作对象按钮。宽容的标题识别只是导航规则，正式标识和写回授权仍使用原有规则。

## 完整正文与往返

复用全文 composer 和来源片段映射，保留完整原句、无标签正文、重复句、局部 TODO、未知标签、多行代码、引文、链接和原缩进。展示标题只存在于报告排版层。

原生输入过程中可以打开阅读，入口不抢焦点、不改 textarea、不强制保存。报告只显示宿主已保存内容，提示「当前输入保存后更新」；Logseq 自行保存后自动刷新。会移动原生焦点、聚焦范围或写回内容的操作仍遵循输入保护。

宽窗并排；分隔线可拖动或用方向键调整，记住宽度。窄窗从真实正文块进入原生编辑后，宿主顶部「返回正文」一次返回，输入可继续保留。正文／材料往返、关闭再开、重启按来源 UUID 和偏移恢复位置。页面 UUID 在文件 Graph 重启后改变时，核验同一 Graph 的页面名，使用宿主当前真实 UUID 重新读取。

## 按需能力

首次真实保存材料才准备 Graph 外的普通目录；阅读不会创建目录。显式工作目录优先于全局材料目录，缺省目录稳定按 Graph 隔离。失败时在这次保存附近选择一次目录并记住，输入和恢复缓存保留。

协作入口保留工作目录、范围与修改许可的明确选择。Logseq 0.10.9 没有可用的任意进程启动接口，因此安装包提供独立协作启动器。启动后自动发现连接文件，用户再允许当前工作连接；连接就绪不代表 agent 已开始工作。基础阅读不依赖启动器或 Node。
