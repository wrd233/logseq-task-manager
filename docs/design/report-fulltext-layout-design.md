# 长篇原文的完整报告排版

报告提供完整原句的阅读版式。原生 Logseq 页面继续负责书写，材料文件与正式状态保留各自权威。读者不需要先把混写正文改成一套新标题，才能读到全部内容。

## 全文与范围

进入报告时默认展开全部来源，不继承原结构模式的折叠、三行显示和紧凑偏好。显式折叠、既有聚焦仍能缩小当前显示；底部显示实际可见条数，展开或退出聚焦可以恢复全文。返回原结构仍保留此前的个人显示偏好。

根 MiniProject 的原句计入一个来源，出现在正文首行；面板标题是导航副本，不重复计数。多行块、列表、表格与代码各自仍属于原来的一个块。重复句按两个真实来源分别出现。未知标记、疑问和未成熟判断保留原措辞。

来源不可用与显式隐藏分别记录，不能因 DOM 中还有上一次正文就宣称当前来源完整。来源身份、完整 raw 版本和实际阅读文字分别核对。

## 重排的确定范围

只有已识别事务或 MiniProject 的直接子级中，连续、明确的已知标记区间可以按目标、记录与说明、想法、待办组织。移动的是带完整后代的子树。相同类别内部保持原顺序；只有一个类别的区间不再添加标题。

普通解释父段下的子级保持真实顺序，不递归地把局部目标和 TODO 抽走。事务和子 MiniProject 固定在原同级位置，其内部可以单独组织，不成为父对象的通用分组。

无标签或未知标记固定自身及左右两个同级邻居。邻接只能证明原来的相邻关系，不能证明语义归属。策略因而保守：大量混写区域保持原顺序，明确标记的小区间获得轻量标题。没有按关键词、句长、相似文本推断归属，也不依赖模型或网络。

标题只有展示 key 和来源集合，没有伪造的 block UUID，不能作为原生编辑、材料落点或写回目标。切换、刷新、分组不会新增标题块、移动真实块、改写正文或执行 TODO。

## 阅读与交互

正文采用自然段，15px 字号、1.8 行高，每层缩进 12px。工作对象首段使用克制的标题层次。空圆点和拖动柄退出报告版式，每行保留折叠入口与一个条目菜单；多行原文对照和原生编辑放在菜单中。

普通双击保留宿主选词行为。原生编辑使用“编辑原文”、键盘 Enter 或 Alt＋双击，经既有来源与版本保护定位真实输入框。正文复制和链接点击不自动打开修改建议输入。

代码保留原文与局部横向滚动，表格可以横向滚动，引文、枚举保留 Markdown 层次，长文件名可换行。同一 materialId 的手写别名分别保留，显示名不被文件名推测覆盖。

当前独立 Desktop 证据覆盖 980×700 紧凑窗口和 1440×813 宽窗口，正文区域分别约 920px 和 520px。明、暗 Logseq 宿主均可读；本轮没有实现 iframe 随宿主切换深色背景，暗宿主中的报告仍为浅色正文。

## 长篇验收样例

样例含根对象和 92 条正文、4,217 个汉字、四层深度、两个事务和一个子 MiniProject，包含重复句、未知标记、条件、反例、代码中的字面 `id::`、表格、引文、多行内容及同材料三种手写引用。真实登记材料另产生一条引用来源，Desktop 总数为 94。
