# 材料列表、阅读与引用交互设计

2026-10-05 更新。当前规则以[材料模块产品设计](materials-module-design.md)为完整入口；本页保留阅读交互的局部约定。早期的搜索、路径输入、列表“加入材料”及静默粘贴收纳已由本轮文件抽屉交互替代。旧 Desktop 截图只代表其标注的验收版本。

## 文件与目录

当前工作材料使用紧凑文件行。局部“文件／目录”页沿用公共正文、材料和审阅导航。文件页只有拖入提示、当前工作文件和必要的状态；不显示搜索框、目录绑定按钮组、agent 状态或独立收纳正文表单。

未绑定时自动准备工作专属目录；目录页的加号通过宿主选择器添加已有目录，可以绑定多个，选择一个作为新材料默认目的地。选择目录登记其中普通文件为本工作参考，保留原件；刷新只读该显式目录。工作区主目录身份继续由 Workspace 管理。

拖入文件默认复制到当前默认目录，保留原件；已在目的地中的精确文件复用关联。文件夹保留磁盘结构，列表展示其中的文件。同步显示文件名与等待状态，处理中显示真实阶段；失败项保留重试，已确认复制不因重试重复生成。成功提示以实际写入、核验和材料记录结果为依据。

## 阅读与编辑

单击名称阅读 Markdown，普通文件交给默认应用。改名用行末菜单，不复用双击；真实 basename 与稳定材料身份分开。可选概述继续属于记录，不改正文或授权。只读阅读不加载 Vditor，明确编辑才进入既有编辑器。

原文件、导入副本、收纳创建分别说明；用途与编辑许可另行判断。参考和输入不给 agent 默认改写权限；导入副本也不扩大权限。草稿需明确恢复，保存和冲突始终绑定原 Graph、ID、实际路径与基础内容。返回正文沿用现有阅读书签和来源位置。

## 链接与长文本

复制链接在用户点击中直接写剪贴板，收到成功回执才提示；失败显示重试，不要求再按快捷键。拖出行继续提供 longdoc 稳定链接；正文拖入沿可信段落插入子块，失败保留材料并给明确继续入口。任意原生鼠标字位不冒充可信落点。

普通长文本先原生粘贴，在启用原有阈值提示设置后弹出一次文件名／收纳决定。取消保留原文；确认复用材料核心。异步期间 Graph、元素或精确粘贴正文变化时，只保存文件，保留现输入并提供复制链接。恢复收纳原文使用当时原文，不用后来编辑后的文件代替。

## 兼容与验证

旧 UUID 文件、全局记录、longdoc 引用、手写别名、历史和恢复仍可读，无自动迁移。目录切换只影响新材料，定位从原独立记录完成；失联继续明确重定位。同父目录外部改名仅用可靠物理身份核对，不以内容 hash 搜索认领。

完整产品边界、自动和实际 Desktop 的验证层见[本轮交接](../implementation/materials-drawer-handoff.md)。Finder、原生目录选择器、IME 和 Undo 的完整人工路径未被模拟事件替代。
