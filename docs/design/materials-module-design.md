# 材料模块产品设计

2026-10-05。描述当前实现；总需求以[工作区协作设计](2026-10-02-workspace-usage-and-interaction-design.md)为准，实际契约见[材料架构](../architecture/materials-module-architecture.md)。本次交互调整覆盖较早增量文档中的搜索、路径输入和静默自动收纳规则；保留材料身份、阅读、授权编辑和恢复边界。

## 目标与范围

材料是当前工作的文件抽屉：默认有保存位置，拖入立即有反馈，单击阅读或外部打开，复制链接可在 Logseq 中继续使用。正文保留在 Graph；每份材料的正文只有一个权威文件。无需连接 Kernel 或 agent 即可使用。

支持工作专属默认目录、多目录关联、文件和文件夹导入、Markdown 收纳与阅读编辑、普通文件外部打开、多工作关联、文件改名、失联重定位、冲突草稿及收纳原文恢复。

不新建完整 Workspace、阶段系统、正式任务层级、Git 编排、全目录监听、全盘查找、自动分类、二进制预览或独立 Agent 服务。主动行动建议保持取消。

## 默认目录与工作归属

未关联目录的工作，在默认材料根目录的 `workspaces/<工作身份>` 下获得专属位置，首次实际保存或打开目录管理时创建。设置中的默认根目录留空时，复用宿主个人目录下的 Graph 专属默认根。没有工作归属的程序收纳仍使用全局根。

一个工作可以关联多个目录；一个目录作为拖入文件和收纳长文本的默认保存位置。“目录”页的加号打开宿主文件管理器的目录选择器，无需输入绝对路径。选择已有目录后，其普通文件登记为当前工作的只读材料，保留名称和位置，不要求分类或说明。可在该页选择默认目录、打开目录、刷新文件或解除关联。

目录设置与正式工作区主目录身份分别保存。增加材料目录或切换默认位置，不重写 Workspace manifest，不改变原文镜像、agent 连接或已有材料的文件位置。旧主目录绑定作为兼容目录继续可用；旧项目组织方式仍可由原接口使用。已选默认目录不可用时停止保存，保留输入，明确说明问题；不暗中换目录。

解除目录关联不会删除文件、材料记录、历史或旧链接。现有定位注册继续留存。当前工作列表只显示本工作关联及明确已有引用；其他工作不默认混入。程序的全局 `list` 与现有总入口继续可用，日常材料页不提供搜索框。

## 连续操作路径

### 拖入与引用

从正文进入“材料”，默认是“文件”页。页面只有局部“文件／目录”切换、简短拖入提示和紧凑列表；沿用共享正文、材料、审阅导航。无“加入材料”、目录绑定按钮组、文件路径表单或材料页收纳文本入口。

拖入文件或文件夹后立即显示名称及等待状态，然后显示“正在加入”。逐项完成后成为正常材料行；失败项保留名称、原因与重试入口。当前宿主没有字节进度回调，因此使用真实阶段状态，不显示伪造百分比。

拖入默认复制到当前工作默认目录，原文件保留；已在该保存目录中的文件直接按精确路径关联。文件夹保留实际子目录结构，列表以其中的文件展示。隐藏元数据目录不导入；最多处理 1000 项、24 层，超过范围保留已处理结果并说明问题。

重名文件使用可读名称加短标识，已有文件不覆盖。复制已完成、材料记录写入失败时，副本保留，当前条目可按原请求重试；重试不重复复制已确认的副本。无法确认的中断复制保留临时文件并说明核验问题，不猜测认领。

单击文件名打开 Markdown 阅读，普通文件交给默认应用。改名在行末操作菜单中完成，保留扩展名与稳定链接。单击立即打开，因此不同时把双击定义为改名。

“复制链接”直接写入剪贴板，成功后才显示已复制。失败显示重试提示，不要求用户再按复制快捷键。拖出材料行仍提供同一种稳定链接；拖入可信正文段时沿用已核验的子块落点和正文 Journal。文件加入成功但正文插入失败时保留材料，并提供补插或复制入口。

### 在 Logseq 中收纳长文本

原 `materialsAutoCapture` 开启设置及长度、非空行阈值延续，默认关闭。开启后，普通长文本先走原生粘贴，再在原生编辑区旁显示一个弹窗：可修改预填文件名，选择“收纳”或“保留原文”。取消、Escape、短文本、代码围栏、内部块、文件粘贴与组合输入保留原生行为。

确认后，复用转换和清洗核心保存 Markdown、独立记录、当时原文及 HTML。仅在原 Graph、原编辑元素和精确粘贴内容仍吻合时，用链接替换这一段；保留前后的既有输入。原生编辑器没有接受插入、宿主把粘贴拆成其他块或用户已经换了位置时，材料仍保存，弹窗说明原文保留并提供直接复制链接。不会重放覆盖当前输入。

保存失败时弹窗保留文件名，原文和恢复记录仍在，可重试同一收纳。切换 Graph 或卸载时关闭本轮弹窗，迟到结果不出现在新工作中。命令“收纳当前块长文本”及人／agent 的程序提交仍使用同一核心，材料页没有独立正文输入表单。

恢复“收纳原文”恢复当时粘贴或提交的内容，按稳定 ID 识别引用，不能用后来编辑过的材料正文替代原始输入。原生撤销不会删除外部材料文件。

### 阅读、编辑、返回

Markdown 默认只读。明确点击“编辑”或“编辑原文件”即表达用户编辑意图，进入已有 Vditor；无需重复确认。自动保存、快捷保存、完成编辑、外部打开、来源与返回正文沿用可靠实现。

参考资料与原始输入默认不给 agent 改写；用户明确编辑和 agent 的单文件授权各自表达。生成文件默认允许 agent 修改，后续人工修改仍受基础版本和预期内容保护。复制到材料目录不自动获得 agent 编辑权限。内容中的 TODO、批注和引用不构成授权。

草稿存在时先提示，用户明确恢复；外部版本冲突保留草稿，提供另存副本与加载外部版本。打开其他材料、切换工作或 Graph 不改变已有编辑的保存目标。返回正文恢复原工作与阅读位置。

## 信息层级与异常

列表以文件名、类型、读取能力和必要的草稿／失联状态为主；详细位置、来源、用途和更多操作留在阅读详情或目录页。系统 ID、版本 hash 和目录索引键留在程序结果中。没有审批计数、逐项分类向导或第二套聊天导航。

旧全局材料、UUID 文件名、`longdoc://` 链接、恢复记录和手写别名继续有效，不自动迁移或改名。稳定身份与保存目的地分开：切换目录、工作或显示文字不会重定位旧材料。失联保留关系和历史，使用明确重定位入口；不全盘搜索，不按同名或内容 hash 自动认领。

核心、界面与调用入口已实现；自动回归覆盖默认目录、多目录选择、精确字节复制、重名、同请求恢复、失败条目重试、直接复制、命名收纳、取消、原文恢复及原有冲突／Graph 保护。完整检查和隔离 Desktop 的实际结果见[本轮交接](../implementation/materials-drawer-handoff.md)。

真实 Finder 鼠标拖放、OS 原生目录选择器的人工操作、真实中文输入法与完整原生撤销链需独立补验；不把模拟事件或选择器测试回执当作这些体验的证明。普通文件 IO 不提供跨进程原子比较交换。跨机器重新接入、完整符号链接防护、目录监听和二进制编辑属于后续事项。
