# 原生编辑与长篇阅读往返

2026-10-05。本分支从固定的 `8529212296f0b65fb78ef7ccd2a2102474d9310a` 完善已经接入 main 的原生编辑／报告流程。生产入口继续消费 `WorkView`、`NativeEditorHost` 和已安装的来源 provider；实际验证在隔离 Logseq 0.10.15 Desktop 中完成。

## 写作与阅读

主写作区域仍是 Logseq 自己的页面和原生 block 输入框。正文默认显示完整报告，保留普通无标签段落、原句、局部 TODO、代码、多层缩进和材料链接。展示标题只参与阅读组织；报告 composer、写回 executor、事务识别和材料权限没有另建实现。

原结构入口保留。新报告不继承旧结构视图的默认折叠或三行压缩；初始报告展开全文，随后主动折叠与聚焦继续有效。阅读模式、折叠、UUID 锚点按 Graph／工作根保存为本次插件会话的展示状态，最多保留 12 份。正文仍由 Logseq／材料来源提供，缓存中没有另一份可写正文。

正文中的选择和双击不自动进入原生编辑。用户通过条目操作里的“编辑原文”或可聚焦条目的 Enter 定位真实 block。链接沿用现有材料／链接处理；材料链接不会被段落导航截获。

“对照原文”展开同一来源快照中的完整原始 block，附当前来源身份与版本。它与“编辑原文”分开：打开条目菜单、对照、继续输入和显示原生区域的鼠标动作保留原生输入焦点。对照不会读取新正文、导航或写回。来源已变化而输入未结束时，报告保留旧快照并显示等待安全刷新的状态。历史对照显示阶段快照文字，不携带当前报告的版本标签。

## 宿主布局

布局使用实际窗口和左右宿主侧栏宽度。阅读面板优先取 520px，在需要时缩到 300px，给原生主区至少保留 560px；空间不足时阅读独占可用区域，显式进入原生编辑后让出面板。

实机静止后的尺寸为：

| 窗口／侧栏 | 实际结果 |
| --- | --- |
| 1440px，无左右侧栏 | 原生 920px，阅读 520px，真正并排 |
| 1440px，左侧栏 246px | 原生 674px，阅读 520px |
| 1440px，右侧栏 576px | 原生 560px，阅读 304px；三者没有重叠 |
| 980px，左侧栏 246px | 阅读时占剩余区域；原生编辑时阅读隐藏，主区 734px |

侧栏本身的展开、动画和宽度调整由 ResizeObserver／MutationObserver 驱动，无须等待窗口 resize。截图与数值使用动画结束后的状态。进入窄窗时，宿主只增加一个“返回正文”按钮；它可通过键盘访问，并沿用 `Cmd/Ctrl+Alt+R` 命令。宽窗不常驻另一条返回栏。

安装版 Desktop 的 `hideMainUI` 会无条件 blur 当前元素，`restoreEditingCursor:false` 也不例外。因此从并排输入切到窄窗时，如果真实原生 textarea 正聚焦，本分支通过 SDK 的 `display:none` 让出面板，避免调用该 blur 路径；下一次打开恢复 display。切换过程中不短暂隐藏原生主区，不赋值 textarea，也不调整其选区。SDK 的 `isMainUIVisible` 在这种视觉让出期间可能仍为 true，消费者应使用 `FeaturePanel.visible`。

“原生页面”是显示宿主区域的视图动作，不改变当前工作、任务、材料权限或 block 结构。正在工作子块中写作时，跟随点击不会把每个子块变成新的工作根；明确打开另一份工作才更换上下文。

## 来源和现场

新导航使用报告片段携带的 `scope`、`sourceId`、`BlockTarget`、`contentVersion`、`structureVersion`。它先核对成员与版本，路由后再读同一安装 provider 核对成员、Graph、根和 raw content hash。显示分组、屏幕顺序和最近编辑块不构成来源证据。

SDK 的路由确认早于原生 DOM 挂载。实现等待 UUID 匹配的真实 block，再调用 `editBlock`；成功条件包括实际 textarea、SDK 当前编辑 UUID 和焦点均匹配。关闭、切换工作／Graph、dispose 或更新请求会使旧请求失效，晚到读取不能发布成新工作的内容。

继续当前输入采用同一 UUID 输入框的焦点复用。Logseq 会在编辑器仍打开时自动保存，因此这条纯焦点路径接受较新的正文版本，但仍核验当前成员、Graph／工作根、可用性和 SDK 编辑 UUID。它不路由、不刷新报告、不加载 value；新导航和写入仍使用严格版本保护。另一块输入、组合态或来源失效会被拒绝。

返回位置使用来源 UUID、可见祖先、偏移、仍有效的 DOM 焦点／文本选区，不保存“第 N 行”。新增、修改和移动后保留有效节点，只替换受影响正文；已删除来源不留下孤立段落。锚点消失时优先使用真实祖先，无法恢复则回到可重新定位的入口。工作被删除时保留最后已知内容并显示来源不可用，不自动采用另一工作或 Graph。

实机已完成中间段落输入／选区／继续、宽窄切换、宿主侧栏、跨页目标、材料往返、阶段历史与当前正文、退出聚焦、来源更新／失效和两个隔离 Graph 往返。系统剪贴板与原生 Undo 通过 macOS Computer Use 自动化验证；它们不是人工物理输入法验收。

## 交接边界

01／06 消费最小 FeaturePanel 宿主接线，公共 navigation/style 的命名与整理由其负责；本分支未重排这些函数。02 消费默认完整阅读及折叠会话策略，composer 分组实现不变。04 消费真实 block 的 `BodyTarget`／原生观察端口和材料返回锚点。05 继续拥有阶段 ReviewPort，历史／当前往返沿用它。

固定 BASE 的实际入口没有注册 `observeNativeDrops` 消费者。本分支保留观察端口的 trusted-event、scope、输入、版本及卸载限制，未复制 MaterialTransfers，也未承诺文件导入、任意原生光标或系统拖放已完成。04 接入后须在真实宿主中验证；含糊落点先提供现有材料的完整 `longdoc://` 引用供用户在原生编辑器中粘贴。

完整证据、通过／失败与未验范围见 [实施交接](../implementation/native-editor-reading-handoff.md)，协议和消费方式见 [架构](../architecture/native-editor-reading-architecture.md)。
