# 工作结构历史只读回放

入口：工作台 → 审阅与历史 → 历史、比较与阶段成果 → 阶段历史 → 工作结构历史；命令“工作台：查看阶段历史”直接展开回放。

## 来源核对与语义

- 生产数据由既有 `StageStore.history(scope)` 提供。读取不可变 StageStart / StageRevision 的完整 SourceSnapshot，沿已核验修订链回放；不读取当前图谱来填补过去。候选修订仅在既有存储显式 resolution 选入正式链后才可出现。
- 存储逐条核验 envelope 哈希、原文哈希、结构哈希、来源身份、修订 fingerprint 与链关系。损坏记录和并发分歧通过 problems 展示；保留可验证部分。候选、认可与正式 Kernel 业务事件语义不同；修订是否已认可单独显示。
- 节点身份是 graphId + block UUID（sourceId），不是标题或数组位置。父子和顺序来自 parentUuid / order / depth。正文第一行变化称“重命名”，其余正文变化称“描述变化”，均为来源文本比较，不能据此宣称 Kernel 工作对象发生语义变更。
- TODO / DONE 等状态来自原文行首标记；依赖只解析 `depends-on:: ((uuid))` 的显式来源声明。未标记显示未知；不猜测自然语言依赖，不把普通块引用变成依赖，不声称这些是 Kernel 正式事实。
- Kernel 目前有 ClosureHistory（完成、取消、修正、重开）以及投影 / 业务记录，但并不是完整工作树在任意时间的历史接口。本实现不拼接这些记录、不将当前 Kernel 值倒填进 Logseq 历史，也不读取代码结构或 Git 提交列表。
- 不跨阶段推断新增/删除。每次比较只对应同阶段明确 parent 修订。起点以前、时点之间未知；任一快照有不可用块时，保守禁止整次新增/删除判定，并显示缺失说明。父修订不在可用链时明确提示无法比较。

## 界面与边界

时间轴、前后按钮和带时间/阶段名称的选择器均可操作。按记录时间排序；显示原文采集与记录时间。对照保持明确父修订，不用时间相邻冒充祖先。

图使用已有 DOM / SVG，不新增图库。节点纵向按首次出现的身份固定；横向反映真实深度。变化有文字与边框；删除用前一修订的原文与位置作为幽灵节点。实线表示归属，虚线表示显式来源依赖。范围外依赖在节点详情保留 UUID，不虚构目标节点。该布局成本是宽树需要水平滚动，复杂树可能有交叉线；用户可随时切换完整目录，超过 250 个可见节点自动降级。

点击图节点或目录项查看完整该时点原文、父块、状态、依赖、变化类别和上一修订原文，并可通过真实 SDK 打开当前来源块。来源定位先检查当前图谱身份与块是否存在；删除或切图会显示错误。历史原文仍可读取。界面只持有数据，不拥有写入、认可、回滚、恢复草案能力。

## 实际宿主验收

在仓库已有隔离沙盒 Logseq 0.10.9 中，通过真实 Editor SDK 新建专用验收块，并用正式 StageRecorder / FileStorage 保存起点与两次修订。不是注入模拟 StageHistory，也没有生产 Fixture 入口。

验收根块：`6ad8f174-b4a2-463a-99fd-30daf04aec51`；阶段：`1abd9780-b401-4fbf-9ff5-02c359cedff1`。

实际覆盖：首次 3 个时点、4 个累计块身份；重启后补充记录得到 4 个时点、5 个累计身份；TODO→DONE、标题与描述变化、移动至另一父块、声明依赖、新增后删除；逐时点点击全部节点，切换目录及图形，检查存储在浏览前后完全一致。图中同一 UUID 的 top 坐标不变，left 随移动改变。宿主记录的重启后实际来源 UUID 发生替换，第四时点如实显示旧身份删除、新身份新增，不按文本合并。原始 ISO 时间保留在证据中，不人为改写为文档日期。

证据：`assets/structure-history/host-result.json` 包含实际节点、原文详情、原始 FileStorage envelope 和完整历史；归档数据另经生产 StageStore 重新验证后测试回放。`host.png` 为首次运行的宿主截图。可在已打开并授权该沙盒工作后运行 `node scripts/structure-history-host-proof.mjs` 重做只读检查。脚本仅连接固定沙盒端口，并核对宿主应用路径与图谱路径。

生产覆盖范围目前只有已保存的 Logseq 阶段快照，无法还原尚未记录的过去。用户业务图谱没有可核验阶段记录时显示空状态；不生成演示历史。未实现正式 Kernel 工作树时间旅行或恢复写入。
