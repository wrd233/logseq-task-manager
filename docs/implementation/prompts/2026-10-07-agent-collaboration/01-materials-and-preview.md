## 用户要得到的行为

材料区天然同步当前工作关联目录。用户或 Agent 直接加文件，界面能找到它；默认只显示当前层文件和文件夹，点击文件夹进入下一层。

材料默认只读。MD、Word、图片、PDF、Excel 在统一预览内阅读；Logseq 中真实文件引用默认进入这里。放大打开实际独立窗口，用户能移动、调尺寸，在 Logseq 继续写作。

Agent 写文件后能便利取得真实 materialId、当前文件名、完整 Markdown reference，把“详见文件”接到笔记中。引用、目录和预览共同使用同一材料身份。

## 实现一：目录天然同步与真实层级

1. 关联根的真实一级内容是默认目录数据。文件、文件夹、来源、面包屑和返回位置清楚；进入子目录再列下一层，一个工作可有多个可辨认的根。
2. 活跃材料区自动发现外部新增/删除/目录变化；回到材料区、宿主获焦点和进入目录时核对。可用 watcher 优先，降级刷新有界、可取消、去抖，不全盘扫描。正常验收规模的新增项约 2 秒可见。
3. 未登记项可直接发现；预览/取引用时通过同一材料服务惰性关联，只读角色、不复制或搬移原件、不自动授予写权限。
4. 处理多个根的重叠、同名文件、多工作已有材料、默认根切换、解除关联与失联。根之外的历史/外部已关联材料仍有可发现入口，不被目录改造藏掉。
5. 部分读取、分页、上限和截断不能解释成删除。工作/Graph 切换取消旧监听和结果；卸载后不留计时器、事件、重复条目。
6. 保留现有行内改名、覆盖菜单、复制反馈、书签和焦点。刷新不清空文件名草稿，不打断编辑，不迁移既有 Workspace 身份或旧文件。

## 实现二：稳定材料身份与文件名引用

1. 提供 B 共用的“可靠目录文件 → 已有/新材料身份 → reference”入口。返回真实 ID、当前文件名、归属、可用性及现有完整 reference，合法同路径重试幂等。
2. 沿用现有 UUID/longdoc 生成器，不另造链接协议、不让 Agent 扫元数据或操作剪贴板。默认引用显示当前文件名，覆盖中文、空格、括号和 Markdown 特殊字符。
3. 可靠改名延续材料身份并更新自动名称；手写别名保留。外部原地保存、移动、删除、同名副本按可靠事实区分。
4. 缺少可信文件身份、目录失联或部分扫描时保留旧记录/引用/历史，报告需核验；不按名称、内容 hash、大小或 mtime 静默合并或重新认领。
5. 导入、外部加入和 Agent 生成同一文件最终取得同一个可靠材料 ID；只读关联和原件仍保持其边界。

## 实现三：五类只读预览

必须达到 [共同格式口径](shared-contract.md)：

| 格式 | 核心阅读能力 |
| --- | --- |
| .md / .markdown | 完整 Markdown、表格、代码、列表、材料链接、本地图片，可靠清洗 |
| .docx | 段落、标题、列表、表格、内嵌图片；不能静默丢掉主要内容 |
| PNG / JPEG / WebP / GIF | 图像正确、原比例、尺寸、适配与缩放，如实说明动画 |
| .pdf | 多页、页码/翻页、缩放，中文和扫描页面可见 |
| .xlsx / .xls / .csv | sheet 切换、行列位置、已保存值、合并单元格及合理大表边界 |

Word 核心是 docx；旧 doc 正确识别并报告真实能力，不能用 docx 成功替它验收。Word 是阅读预览；Excel 不编辑、不重新算公式，无保存值时明确说明。损坏、加密、超限及未完整呈现就地反馈，不把文件元信息/默认应用打开算内置预览。

具体要求：

1. 统一预览目标、工作范围、可靠身份、格式、真实读取版本、加载/失败/失联与返回位置。原文件仍是唯一材料正文来源。
2. 用可信宿主能力按原始字节读取；必要扩展 FileIO 保持文本调用兼容。不把 UTF-8 字符串重新转码冒充原二进制，保留路径和作用域校验。
3. 实现各格式 renderer；新依赖核对官方文档、许可证、运行时/打包兼容。worker、字体/资源和样式随安装包交付，基础阅读不依赖临时 CDN。
4. 列表、longdoc、可靠 Graph assets/本地文件引用使用同一解析/预览服务。Graph assets 只读解析、不搬移；网页/wiki/页面链接不当成材料。不能可靠解析的路径报告原因。
5. 对 B 提供清晰的正文点击委托。文件链接不再触发整行来源高亮；打开预览保留原生草稿、选区、中文组合输入及阅读/材料位置。
6. 预览无保存、改名或转换覆盖动作。既有 Markdown 编辑单独进入原 Vditor、权限、草稿、冲突和保存路径。
7. 沿用当前材料视觉与菜单，以内容为主体；窄面板、明暗主题、长名称、大表可用。格式控件按内容出现，避免技术控制台。

## 实现四：真正独立的预览窗口

1. 放大打开可移动、可调尺寸、可独立关闭的实际窗口，保持同一目标材料和读取版本；Logseq 仍能继续原工作。
2. 文件改动、改名、删除、失联均有真实状态。切换工作/Graph 或迟到请求不能让窗口显示另一材料。
3. 关闭、卸载、目标失效释放对象 URL、worker、监听等资源。独立窗口默认只读，不能绕过主界面的编辑权限。
4. 在正常插件安装后验证能力，不能把同面板扩大、iframe 模态框、外部应用或 Lab 注入标为独立窗口完成。

若实际宿主阻碍某项核心能力，持续核验并提供可审查的能力验证/替代方案，明确缺口；不能用换名称的交互掩盖未完成。

## 关键验证

- 两个真实材料根、同名文件、两层文件夹：外部加入五类文件自动出现一级项；进入/返回正确；一个根失联不破坏另一个。
- 导入、外部加入、Agent 产物调用同一解析入口取得同一 ID/reference；可靠改名后旧引用仍可达，原地保存、复制、缺身份、截断不错误认领。
- 中文合成文件：docx 含标题/表格/图片；PDF 多页含扫描页；Excel 多 sheet、合并单元格、较长表。分别从列表和真实原生链接进入。
- 预览、翻页/缩放/sheet、独立窗口、关闭/返回后，原文件字节和原生编辑草稿不变；记录实际运行窗口与目标版本。
- 快速工作/Graph 切换、外部变更/损坏/删除、正在改名和卸载：状态、焦点、监听与资源清理正确。
- 不启动 Kernel/companion 仍可目录浏览、发现和预览；安装包解压到仓库外、不用开发服务，实际格式资源/worker 可用。

对身份、字节保真、范围/版本、资源生命周期和有意义的交互冲突加必要回归，跑仓库所要求检查。测试正文语义标记用 `**[标记]**`，只读预览不为外观改原件或 Graph。
