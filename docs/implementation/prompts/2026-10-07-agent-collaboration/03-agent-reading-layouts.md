## 产品目标

Agent 可根据内容给出适合这篇记录的多种读法。文字仍取自 Logseq 原句，变化发生在段落排布、聚合、顺序、对照和布局。用户可以选读法、切回原结构、直接点击一行或小标题，在左侧看到对应来源。

阅读不是生成另一篇改写后的文章。完整呈现原文和条件，同时保留“可能”“不过”“还没想清楚”、父子关系、重复记录以及尚未决定的内容。

## 必须实现

1. 建立独立、版本化、可校验的阅读方案表示和实际 renderer。方案引用真实来源 ID、正文版本、结构版本和完整范围；主体文字由插件取来源，Agent 不提供替代全文。
2. 采用可组合的有限布局单元，使 Agent 能针对内容定制读法，而非只能三选一固定模板。至少展示同一长原文的两种有明显差别、可切换的有效方案：如围绕问题/条件阅读，或围绕推进过程阅读。支持适当连续段落、分组、对照、顺序及材料入口；不执行 Agent 提供的任意 HTML、脚本或样式。
3. 保证完整性：所有应显示的原句都出现；未知/无标签正文、重复块、表格、代码、引文、多行内容、条件、例外和反证都保留。上下文所依赖的父子关系不会因跨组收集被误解。无法证明某处重排安全时，保留原顺序或补足可核对上下文。
4. 小标题明确属于阅读层，没有伪造的可写 UUID。每个展示组拥有真实来源集合；标题不能把不确定想法改名为已确定结论，也不能猜测项目已完成。
5. 点击正文行本身，高亮其来源块及下属内容。点击“目标”等小标题，高亮该组实际引用的全部块、下属内容及必要上下文，采用并集去重而不合并正文来源。不同位置的重复句分别映射。
6. 高亮落在真实 Logseq 原生块上，不修改其正文、层级、属性、TODO 和认可。默认不进入编辑，不重建 textarea、不灌回 value；不因点击阅读层丢失正在写的内容、光标、选区和组合输入。
7. 集合跨越折叠/未挂载块或多个可读页面时，表达实际可见范围并使用真实宿主导航能力，不声称不可见 DOM 已被高亮。不为了高亮而持久写正文/层级；若展开需要额外宿主动作，采用明确且可恢复的交互。
8. 支持键盘、焦点和取消；文本选择/复制不误触来源定位。正文里的材料链接点击优先走预览支的统一路由，不能再触发整行高亮。已选来源、高亮生命周期和定位反馈清楚、克制。
9. 多阅读方案、原结构、正文/材料/历史往返保存位置和有效焦点。来源变更、快速问题切换、Graph/工作切换、卸载后旧方案和高亮不能留在新现场。
10. 对外提供 Agent 可调用的方案读取/提交入口及能力描述，由协作支接入已有通道。它是呈现能力，不能获得写回、任务完成或阶段认可权限。
11. 所有当前真实页面型 Project/Area 与块型对象继续使用真实身份；不得为页面构造可写根块。历史只读及其来源版本继续可核对。

## 行首格式与原文边界

新写作和明确格式整理使用 `**[目标]**`、`**[想法]**`、`**[注]**` 等双星号形式；旧裸标记继续兼容读取。你只处理阅读投影，不能为加粗、添加小标题或选读法写回原文。代码、引文和句中 `[想法]` 等字面示例继续按原样显示。

原文写回和模板规范由协作支承担。必要的解析兼容以现有语法为准，不放宽正式对象判定。

## 文件归属与交接

你拥有 `features/work-view`、阅读方案类型/校验、原生来源集合高亮模块及必要的 `native-editor.ts` 读取定位能力。材料身份、目录观察、预览内容和任务写回不属于本支。

公共组合根、公共导出和跨模块装配由整合支协调。Agent router/CLI 的调用适配由协作支完成，你交付实际 API、输入输出样例、失效原因和版本约定。

## 关键验证

- 复用现有至少 80 块、约 4,000 中文字符、四层关系的合成 fixture，加上两个不同来源的重复句、多个目标、条件/例外和材料链接。
- 两种方案和原结构逐个核对完整原句、实际来源及关系；切换读法后 Graph 原始内容/结构/版本不变。
- 在真实 Desktop 点击一个段落、含后代的段落以及“目标”组标题，核对高亮 UUID 集合；标题自身没有被当作可写来源。
- 文件链接点击打开只读预览；选择文字/复制不误触高亮；真实原生输入正在进行时不被重建、清空或强制提交。
- 原文被用户补充、改 TODO、调整层级或切换工作后，过期方案/晚到结果/高亮正确失效，重新读取再继续。
- 验证折叠块、窄面板、明暗主题、历史、原生侧栏与材料返回；未验收物理 IME 时不把程序事件等同实测。

对来源集合、完整性、版本、交互冲突和生命周期建立必要回归；真实高亮证据来自安装后的插件，不来自 HTML。
