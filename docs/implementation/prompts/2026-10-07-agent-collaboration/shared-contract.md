# 两分支共同约定与接口边界

2026-10-07，修订 2。两支执行前必须读取本文件；保留本轮共识，不依赖此前聊天。新增操作名描述设计职责，不能宣称基线已经存在对应 API。实现以仓库真实类型、宿主能力和必要的兼容演进为准。

## 用户怎样使用

用户主要在 Logseq 原生页面记录与编辑，工作台是完整原文的阅读层。界面继续采用现有暖灰、纸面、低饱和青绿色、紧凑工作身份和正文/材料入口；新能力通过内容与日常动作表达。

Agent 有三种可以结合的作用：

| 作用 | 实际改变 | 共识 |
| --- | --- | --- |
| 阅读编排 | 阅读方案、排序、分组、对照、布局和来源定位 | 原文不变；呈现全部原句、条件、父子语义和不确定判断 |
| 文件工作 | 允许范围内的真实文件 | 产物在工作目录可找到，能取得真实材料引用和文件名 |
| 笔记协作 | 明确范围内的实际笔记、格式和获授权的普通 TODO | 使用真实来源与受限写回；有依据地改变状态，保留来源和恢复路径 |

最重要的写作偏好是：**保留我的语气、思考过程和不确定判断**。不要把零散记录自动变成正式方案文风。用户明确要求改写时依指示进行，并保留可回看的旧版本。

三条过程都要成立：

1. 做事时顺带记录：一条有意义的阶段变化续接原任务，必要产物链接放旁边，完成依据成立后才维护普通 TODO。工具调用本身不生成永久笔记。
2. 项目初期讨论：谨慎留下值得继续使用的想法、注意点、条件和权衡；围绕同一问题续写，不每轮增加一份总结。
3. 随手记后继续：先提供适合阅读的编排；用户要求时才整理真实文本/格式，含义不清时继续交流。半句话、问号、重复句和犹豫不自动删除。

风格例子：用户写“可能湖边更舒服，不过还得看天气”，阅读层保留原句；协作补充可接“**[注]** 如果下雨，先保留室内备选”。不能改成“已确定湖边方案”，也不能无依据标完成。

## 权威来源、身份和版本

1. Logseq 笔记通过真实来源 provider 与既有 executor 读取/变更。工作目录中的原文镜像是派生读取材料，不是 Graph 正文的直接写入目标。
2. 材料正文以原文件为准；阅读方案引用来源，不保存另一份改写正文。草稿、已保存原文、缓存、历史和阅读方案明确区分。
3. 保留真实工作、Graph、块/页面、正文版本、结构版本、材料身份和读取版本。目录、标题、同名文件和路径不能冒充对象身份。
4. 结果表达真实成功、部分成功、不可用、冲突与未知。缓存、mtime/大小不能冒充权威核验的内容或字节版本。
5. 异步请求携带工作范围、版本与请求归属。工作/Graph 切换、重绑定、撤销、卸载后，旧调用和高亮失效。
6. 未知写入通过原 requestId 查询与恢复，不更换 ID 盲目重做。用户同时改笔记时，过期提议不得覆盖新内容。

## A → B 的材料接口语义

共享链：`浏览关联目录 → 确认真实文件 → 复用/关联材料身份 → 获得 reference → 只读预览`。

| 职责 | 必须表达的事实 | 归属 |
| --- | --- | --- |
| 单层目录浏览 | 当前工作、关联根、相对位置、一级文件/目录、可用性和截断/读取问题 | A；B 的 Agent 入口适配 |
| 解析目录文件 | 受信范围、真实文件、已有身份或惰性关联结果；幂等、不复制原件 | A；B 调用 |
| 材料引用 | 真实 materialId、当前文件名、完整 Markdown reference、归属与可用性 | A 提供；B 直接使用 |
| 只读读取 | 可靠材料/本地文件来源、真实字节/文本、读取版本、格式、可用性 | A |
| 打开预览 | 已验证目标、面板/独立窗口、返回位置、失效与资源释放 | A；B 的正文点击委托 |

这张表固定跨支含义，具体函数以现有 `MaterialRecord`、`MaterialView.reference`、范围/版本类型为基础。A 在 handoff 给出最终导出和输入输出；B 在自己分支合入 A 后完成真实适配。B 在并行期间可以先复用已有材料读取/关联结果中的 reference，不能复制材料算法或长期保留假实现。

稳定引用沿用 `longdoc://<真实材料ID>` 与现有生成器。默认显示当前真实文件名，正确转义中文、空格、括号和 Markdown 特殊字符；用户手写别名另保留。Agent 不自己拼 UUID、不用 `[[文件名]]` 冒充材料引用、不需操作剪贴板。

未登记目录项可先浏览，预览/取引用时通过同一服务惰性关联。只读关联不自动授予写权限，不为链接复制文件。可靠改名延续身份；外部保存、移动、删除、同名副本按可靠事实区分，不能按名称/hash/大小/时间静默合并。失联仍保留可核对记录与历史。

材料区无需 Agent/Kernel 连接即可发现目录变化。根只显示当前层的文件与文件夹，点击进入下一层。宿主缺少 watcher 时采用有界、可取消、去抖的实际刷新；正常验收规模的活跃界面新增项约 2 秒可见，超限/部分读取明确展示，不能解释成删除。

## 预览口径

| 类别 | 核心格式 | 阅读要求与边界 |
| --- | --- | --- |
| Markdown | .md、.markdown | 完整 Markdown、表格/列表/代码、本地图片、材料链接 |
| Word | .docx | 段落、标题、列表、表格、内嵌图片；阅读预览。旧 .doc 正确识别，报告实际能力 |
| 图片 | PNG、JPEG、WebP、GIF | 原比例、尺寸、适配/缩放；如实说明动画能力 |
| PDF | .pdf | 多页、页码/翻页、缩放；中文与扫描页可见 |
| Excel | .xlsx、.xls、.csv | sheet、行列、已保存值、合并单元格；说明大表/公式缓存边界 |

预览默认只读，不保存或转换覆盖原文件。已有 Markdown 编辑是单独动作。旧 .doc 没有验收不能列为已支持；Excel 不负责编辑或重新计算公式。损坏、加密、超限及未完整呈现有就地、准确的反馈。

材料列表、原生 Logseq 稳定链接、可靠本地资产链接、正文文件链接和 Agent 引用走同一预览路径。页面/wiki/网页链接保留其语义。Graph assets 只读解析不搬移文件，不改 Graph 外材料根规则。

放大必须是实际可移动、可调尺寸的独立窗口。窗口、字节读取、worker 和打包资源需在正常安装的目标 Logseq 验证；同面板扩大、默认应用或 Lab 专属注入不能算完成。

## 阅读方案与高亮

- 方案版本化、可校验，引用真实来源 ID、范围、正文/结构版本与有限可组合布局单元。文字由插件从来源读取，不执行 Agent 的任意 HTML、脚本或样式。
- 可以连续段落、分组、对照、顺序、材料入口自由组合，至少两种明显不同的有效读法。保留原结构入口。
- 完整呈现全部应有原句、无标签块、重复来源、表格、代码、引文、多行、条件、例外和反证。重排保留语义依赖的父子关系；不能证明安全时保留原序或补齐上下文。
- 标题是阅读层说明，不能把不确定想法包装为结论，也没有伪造的可写 UUID。
- 点击正文高亮该来源及后代；点击标题高亮该组来源、后代及必要上下文的并集。重复句分别映射。
- 高亮使用独立来源集合定位，默认不进入编辑，不重建 textarea、不写回，不改 TODO/属性/层级/认可。选择、复制、草稿、光标、中文组合输入受到保护。
- 文件链接点击只进入材料预览；不会同时触发行定位。过期方案先重读，不将旧偏移或层级套到新原文。
- 折叠、未挂载和跨页面来源按真实宿主能力导航，清楚说明实际可见集合。书签、历史、范围切换和卸载仍可靠。

## 协作现场与一处共同指导

外部 Agent 现场包括：真实工作身份、已保存原文/层级/版本、材料及相关文件、当前用户请求、必要的选定讨论背景、阅读方案、共同指导与项目补充的版本、本次许可范围。导出不强制结束原生输入，不抓全量聊天。

复用 WORKSPACE/manifest 与既有私有本机 companion/CLI；已有用户 WORKSPACE.md 不被覆盖。运行环境先真实刷新，明确 last-known 与已核验来源。不另建聊天库或 Kernel 路径绕过当前边界。

共同指导只有一份维护来源，各工作区引用它或生成带版本副本；项目仅写差异。入口记录此次实际加载的版本，旧现场可重读。不同 Agent 用各自真实加载机制；普通文件/软链接不会保证任意 Agent 自动读取或让当前会话即时重载。

用户明确编辑共同指导才改变长期维护来源；局部建议不自动变为所有项目规则。具体产品的接入方式核对真实机制和官方资料，不覆盖全局配置、不写入 Codex 记忆。没有可靠会话链接时如实处理，不自动新建/联系其他聊天。

## 写回与普通 TODO

正文补充/格式整理走既有 content.read/apply/result/recover/retry、范围校验与 Journal，保留作者来源、基础版本、目标落点和恢复记录。同一请求/阶段重试幂等；进展续接既有主题，详细产物放材料。

普通 TODO 维护是单独的明确授权，读取、编排、正文写作、文件写作不自动包含状态权限。授权来自真实本地受信入口，限定当前工作、目标范围、操作和生命周期；外部 payload 不能自选 actor/root/授权。

在已经获准的范围内不反复确认小操作，但执行前仍核验对象、版本、完成依据。一个子步骤完成不推断项目完成；想法/问题不自动变 TODO；正式任务、事务、受管字段和阶段认可继续走既有正式端口，Agent 不代用户认可。

## 所有语义行首标记用双星号

```markdown
- **[想法]** 我目前偏向湖边，不过还要看天气。
  - **[注]** 如果同行的人很累，就别安排必须打卡的地方。
- **[记录]** 两处交通已比较，住宿取消条件还没核对。
- **[问题]** “可取消”是不是等于全额退款？
- TODO 核对取消条款。
```

新生成或用户明确要求整理的语义标记均采用 `**[标记]**`，包括目标、想法、注、说明、记录、问题及其他现有语义标记。普通 TODO 不新增 `[任务]`/`[事务]`，这些标签触及正式语法保护。已有正式对象锚点如 `TODO **[任务]** ...`、`TODO **[事务]** ...` 与受管字段复用 `canonical-writing.ts` 和正式路径。TODO/DONE 位于 Logseq 原生语法位置，不写为 `**TODO**`。

旧裸标记继续兼容读取；只换读法不顺便写回加粗。实际格式整理限定用户要求范围，预览差异，保留措辞、UUID、层级、属性和状态。代码、引文、句中示例不自动处理，不能借格式整理绕过正式保护。

## 只有 A、B 两个所有者

所有源码位置均从仓库根计算，插件主要位于 `apps/logseq-plugin/src/`。

| 所有者 | 主要区域 | 共享处怎样处理 |
| --- | --- | --- |
| A · 材料 | features/materials、目录观察核心、稳定引用、本地文件解析、预览模块/窗口、host/file-io、构建资源 | 材料 controller 和预览依赖/lockfile 由 A 维护。workspace-files 的观察核心归 A，Agent 协议装配归 B |
| B · 阅读与协作 | features/work-view、来源集合高亮与 native-editor 定位、features/agent-workspace、content-writeback、工作区指导、CLI/协议适配 | workspace-agent.ts 的命令演进归 B；调用 A 的真实服务，不在 router 复制材料算法 |
| B · 最后联调 | 应用组合、公共导出、冲突解决、统一视觉、最终验收、用户指南与安装包 | 在 B 分支合入 A 的完整提交，不建立第三实施分支 |

两支允许必要的最小接线完成真实局部验证，不同时重排共享大文件。公共类型按职责归属演进，破坏性变化记录契约修订/输入输出和适配影响。A 交接实际修改文件、公开接口、完整 SHA；B 逐项接线并核验，不仅收集报告。

## 验证与交付

- 两支独立工作树，隔离 Graph、材料、profile、端口、进程和通道状态。保留用户已有修改，不占用其生产笔记或正在体验的 Lab。
- 沿用视觉、全文完整性、材料改名/复制、书签、草稿、历史、主题和范围撤销保护。
- 做有必要的针对性回归与仓库要求检查。B 最后至少执行 npm run check、npm run package:plugin，解压安装包到仓库外做真实 Desktop 联调。
- 新预览、真实独立窗口、原生引用、集合高亮、外部新增目录文件及协作写回均须有实际证据。HTML、解析器单测、假回执和 Lab 专属能力不能替代安装后行为。
- 未验证的平台/宿主版本、物理 IME/Finder/剪贴板和普通文件 IO 竞态如实列出。未知结果、未接线和未验收格式不算通过。
- 默认仅隔离实施、必要验证和本地提交，B 可在自己的实施分支合入 A。推送、PR、main、发布及创建/联系其他聊天另依用户明确指令；不再拆分实施分支或委派额外 Agent。
