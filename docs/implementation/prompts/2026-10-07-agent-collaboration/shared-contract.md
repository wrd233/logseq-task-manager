# 并行实施共同约定与接口边界

这是本轮的设计约定。下文新增的操作名称描述职责，不声称仓库已经存在这些 API。实际类型、导出和参数在整合分支的共同基线准备中核对、固定；优先复用现有类型。

## 来源和版本

1. Logseq 笔记通过真实来源 provider 和已有写回 executor 读取、变更。工作目录中的原文镜像是派生读取材料，不可直接当成 Graph 正文写回。
2. 工作身份、Graph、块或页面身份、正文版本、结构版本、材料身份与版本分别保留。目录路径、同名文件、显示标题不能替代身份。
3. 公共结果保留实际的成功、部分成功、不可用、冲突与未知结果。缓存和文件大小/时间不能冒充经过权威核验的正文或字节版本。
4. 任何跨工作异步结果携带范围和请求归属；Graph 切换、重新绑定、撤销授权、卸载后旧请求失效。

## 材料目录 → 引用 → 预览

共享职责链：`浏览关联目录 → 确认真实文件 → 复用/关联材料身份 → 获得 reference → 只读预览`。

| 操作职责 | 必须表达的事实 | 所有者 / 消费者 |
| --- | --- | --- |
| 单层目录浏览 | 当前工作、关联根、相对位置、一级文件/目录、可用性、截断/读取问题 | 目录支；预览与 Agent 消费 |
| 解析文件为材料 | 受信目录范围、真实文件、已有身份或惰性关联结果；幂等且不复制源文件 | 目录支；预览与 Agent 消费 |
| 材料引用 | 真实 `materialId`、当前文件名、已有稳定 `reference`、材料归属；手写别名另保留 | 目录支提供；Agent 使用；预览支解析 |
| 只读读取 | 材料身份或可靠本地文件来源、真实字节/文本、版本、格式与可用性 | 预览支；阅读 UI 与独立窗口消费 |
| 预览打开 | 已验证目标、面板或独立窗口、返回位置、失效与资源释放 | 预览支；目录、正文链接和工作台消费 |

未登记的目录文件可以先作为发现条目显示；点击预览或请求稳定引用时，通过同一材料服务惰性关联。只读关联不自动授予 Agent 写权限。不得为了给出链接创建第二份文件。

稳定引用继续采用仓库已有的 `longdoc://<真实材料ID>` 语义及生成器。Agent 使用服务返回的完整 Markdown `reference`；不能把文件名造为 UUID，也不能用 `[[文件名]]` 冒充材料链接。默认显示真实文件名；自动名称随可靠改名同步，用户手写别名保留。

一个材料在目录浏览和旧引用中保持同一身份。外部原地保存、改名、移动、删除、同名复制按可靠事实区分；缺少可靠身份时说明需要核验，不按名称、内容 hash、大小或时间静默合并。解除关联不删除文件、记录和历史。

目录可见性无需 Kernel 或 Agent 连接。目录监听若宿主不支持，采用有界刷新等实际可用机制；活跃材料区在正常验收规模下自动发现新增项，目标在 2 秒左右显示，超过能力边界显示真实状态。回到界面和进入子目录必须重新核对。分页/截断不能被解释成删除。

预览只读是默认进入方式，不能触发保存、改名或自动格式转换后覆盖原文件。已有 Markdown 编辑动作单独进入原有编辑路径。普通本地文件引用和 Graph assets 的路径解析必须有真实来源；网页及 Logseq 页面链接保持其含义。

## 原文 → 阅读方案 → 来源高亮

一个阅读方案包含：版本化工作范围、引用的真实来源集合、布局单元及关系、明确属于阅读层的标题/说明。源正文由 renderer 读取，Agent 不提供替代全文。

- 支持组合，而非仅固定的“目标 / 想法 / TODO”模板。可以组合连续段落、局部分组、对照、顺序和材料入口；组件种类是可解释、可校验的有限集合。
- 调整展示顺序时保持语义所依赖的父子、条件、例外和未确认判断。对一组想法的标题不能擅自改成“已确定方案”。
- 完整阅读不能无声删句、去重、截断或者隐藏未分类块。两个内容相同的块保持两个来源。必要条件和反例不能为了突出结论被藏起来。
- 段落点击目标是该来源及其下属内容；标题点击目标是该展示组实际来源与必要上下文的并集。标题本身没有伪造的可写 UUID。
- 高亮采用独立的“来源集合”职责，绝不能复用“打开原生编辑”来制造效果。点击嵌入的文件链接仍打开材料；选中文字、复制、中文输入和现有原生草稿受到保护。
- 版本或范围过期时重新读取，不把旧偏移、旧层级或旧高亮套到新原文。高亮只改变宿主可视状态，不改原文、层级、TODO 或认可状态。

## Agent 协作与共享约定

协作现场包含：真实工作身份和已保存来源、材料与相关文件、当前用户请求、必要的讨论背景、当前阅读方案、共用指导和项目补充的版本、此次许可范围。草稿、缓存和已保存原文明确区分。

共享约定只有一个维护来源；工作区入口引用或按版本生成派生副本。加载记录能说明此次 Agent 实际读到哪个版本。不同 Agent 平台通过各自入口加载，不能声称任意 Agent 会自动读取一个新文件。项目只写差异，不能每次导出都生成互相竞争的共同规则。

共同写作默认遵守：保留用户的语气、思考过程和不确定判断；在现有想法/任务下面补充有效条件、进展、依据和下一步。用户明确要求重写时再按其指示改写，并保留可回看的来源版本。没有每次对话自动总结和全量聊天抓取。

记录单位是有后续价值的问题、结果或推进变化。不是“调用了一次工具”“看了一个网页”“说了一句话”。同一阶段的记录更新或续接现有落点，重试不产生重复笔记。

普通 TODO 的授权单独、明确且受范围约束：读取、改正文、编排、写文件均不自动授权改任务状态。在用户已明确允许当前工作的相关普通 TODO 维护后，范围内无需每个小操作重复确认。执行前仍验证对象、版本与完成条件；模糊的新含义先交流。正式任务、事务、阶段认可使用既有正式程序端口，不让自然正文替换绕过它们。

## 统一行首格式

所有新生成或明确整理的语义行首标记采用双星号加粗，包括：

```markdown
- **[MiniProject]** 整理一次周末短途旅行 #MiniProject
  - **[目标]** 选出一个节奏轻松的目的地。
  - **[想法]** 可能湖边更合适，但现在还不确定。
    - **[注]** 如果下雨，可以改为室内活动。
  - **[记录]** 交通已比较，住宿条款仍需核对。
  - **[问题]** “可取消”是不是等于全额退款？
  - TODO 核对住宿条款。
```

`**[说明]**`、`**[事务]**` 及已有语义标记遵循同样格式。已有正式锚点如 `TODO **[任务]** ...`、`TODO **[事务]** ...` 复用 `canonical-writing.ts`；普通 TODO 不新增 `[任务]` / `[事务]` 装饰。这些标签触及正式语法保护，不能为了统一外观把普通待办变成正式对象。`TODO` / `DONE` 继续位于原生任务语法的位置，不写成 `**TODO**`。

旧 `[想法]` 等裸标记继续兼容读取；只换阅读编排不顺便写回加粗。需要规范现有笔记时，作为用户明确要求的格式整理：限定当前范围、预览差异、保留 UUID/层级/正文/属性/状态，并使用既有写回路径；正式锚点/受管字段的格式规范走其正式路径，不绕过自然正文保护。代码、引用、行内示例和句子中间的字面标记不自动处理。

## 文件归属与并行规则

| 所有者 | 主要可修改区域 | 共享文件处理 |
| --- | --- | --- |
| 目录支 | 材料目录浏览、身份/目录服务、文件列表、目录 UI、引用名称；现有 `workspace-files.ts` 的观察核心 | `materials/controller.ts` 的列表部分归此支；预览通过预先约定的接口接入 |
| 预览支 | 新材料预览模块、各格式 renderer、独立窗口、预览相关 `FileIO` 扩展、本地字节读取、构建资源 | 预览依赖与 lockfile 由此支集中维护；不重写材料列表/目录状态 |
| 阅读支 | `features/work-view`、来源集合与高亮宿主模块、阅读计划类型、`native-editor.ts` 的读取定位能力 | 高亮不写回；材料点击委托预览入口；不改文件身份 |
| 协作支 | Agent router/installer、工作区上下文/指导、CLI/companion 的调用装配、自然正文写回与普通 TODO 授权 | `workspace-agent.ts` 命令扩展归此支；不复制目录观察或预览算法 |
| 整合支 | 应用组合根、公共导出/接线、共享视觉、验收 fixtures、需求索引和最终交付 | 先固定必要扩展点；后统一合并根入口、冲突与版本 |

路径如有调整先找实际等价位置。所有者可以为正常调用增加最小边界接线，但公共装配大改必须集中。不能在自己的分支复制他支整个模块，也不能同时清洗共享大文件。交接提供适配说明、实际改动文件和完整提交 SHA。

## 验证与交付共同规则

- 用隔离 Graph、材料根、应用 profile、进程、端口和独立工作树。不得占用正在给用户体验的 Lab，也不碰生产 Logseq。
- 沿用已完成视觉、原文完整性、材料改名/复制、书签、草稿、历史、主题和范围撤销保护。
- 跑必要的针对性测试与仓库要求的检查；整合完成后执行 `npm run check`、`npm run package:plugin`，用解压后的安装包做真实 Desktop 联调。
- 新格式预览、独立窗口、文件引用点击、集合高亮与外部新增目录文件必须有真实行为证明。HTML 稿、模拟点击、Lab 专属 IPC 和解析器单测不能冒充安装后能力。
- 未实测的 OS、Logseq 版本、物理 IME/Finder/剪贴板操作以及不可消除的普通文件 IO 竞态如实列出。不能把未接线模块或未知写入结果算成完成。
- 完成自身分支的实现和交接；不再创建其他聊天、派子 Agent、自动联系其他会话、推送、发布或合入用户主分支，除非用户另有明确指令。
