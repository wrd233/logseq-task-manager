请在一个实施分支完成阅读方案、来源集合高亮、外部 Agent 现场、共同指导、共同写作与获授权的普通 TODO。随后在本分支合入 A，交付真实可用的完整闭环、安装包和验证。不要停在 HTML、模板、模拟 router 或几份完成报告。

建议分支：`codex/reading-and-agent-collaboration`。A 负责完整材料路径；本轮只有两条实施分支，最后联调由你承担，不另开整合分支。

## 核心体验

用户最在意：**保留我的语气、思考过程和不确定判断**。

Agent 可以仅改变读法、在工作目录写实际文件、按指导真正补充/整理笔记和维护获授权的普通 TODO。这些作用可以结合，但不因读取/编排就取得写回或状态权限。日常界面不要求用户填写 UUID、协议或补丁 JSON。

三条过程都实现：做事时围绕现有任务记录有意义的阶段变化；初期讨论谨慎沉淀想法/条件/权衡；零散笔记先编排，按用户需要再整理或继续讨论。详细产物放材料，不每轮增加一份总结树。

## 实现一：可组合阅读方案

1. 建立独立、版本化、可校验的方案：真实工作范围、来源 ID、正文/结构版本、完整来源集合、有限可组合布局单元和关系。正文由插件从来源取，Agent 不提交替代全文。
2. 支持连续段落、局部分组、顺序、对照与材料入口等组合，使 Agent 针对内容设计读法，不只三选一模板。至少交付同一长原文两种明显不同的有效方案，保留原结构与既有聚焦/取消/上一问题。
3. 全部原句、未知/无标签、重复来源、表格、代码、引文、多行、条件、例外与反证完整在场。跨组重排保留语义依赖的父子关系；不能证明安全时保留原序或补足上下文。
4. 小标题属于阅读层，来源集合可核对，没有伪造的可写 UUID。不能把“可能/不过/还没想清楚”框成已确定结论或完成状态。
5. 多方案、原结构、材料/历史往返保存有效位置和焦点；版本过期先重读，范围切换/卸载使晚到方案失效。
6. 通过你负责的既有 Agent 通道接入真实方案读取/提交和能力说明；不执行 Agent 任意 HTML/脚本/样式，也不因此授权写回/TODO/认可。

## 实现二：点正文或标题，集合高亮真实来源

1. 点击正文行高亮该来源及下属内容；点击“目标”等标题高亮组内真实来源、下属内容及必要上下文并集。不同来源的重复句分别映射。
2. 高亮作用于实际 Logseq 原生块，默认不进入编辑，不改正文、层级、属性、TODO、认可；不重建 textarea、不回灌 value、不丢草稿/光标/选区/中文组合输入。
3. 使用独立来源集合定位端口，不能直接复用进入原生编辑制造效果。折叠/未挂载/跨页面按真实宿主导航，清楚表达实际可见来源，不声称不可见 DOM 已高亮。
4. 正文/标题操作支持键盘和取消；选文字、复制不误触定位。嵌入材料链接优先委托 A 的统一预览，不再触发整行高亮。
5. 页面型 Project/Area、块型对象继续使用真实身份；页面不伪造可写根块。历史只读、来源版本、书签与范围撤销保护保持。

## 实现三：带当前工作去协作

1. 形成可让外部 Agent 继续的入口：真实身份/范围、已保存原文/层级/版本、材料与相关文件、用户当前请求、必要选定背景、当前阅读方案、指导版本和本次许可。
2. 已保存内容、草稿、缓存和展示方案区分；导出不强制结束原生输入，不悄悄将未保存内容当正式原文，不抓全量聊天。
3. 复用 WORKSPACE、manifest 和来源发布；已有用户 WORKSPACE.md 不覆盖。刷新真实现场，标明 last-known 与核验结果，不另造身份/聊天库/MCP/Kernel 路径。
4. 给用户易用的“带当前工作去协作”：复用已有会话关联/读取入口、启动语或用户选择的可靠链接。没有链接如实处理，不编造跳转、不自动创建/联系其他聊天。
5. 外部调用不能自选 actor/root/权限。Graph/工作切换、重绑定、撤销、卸载使旧调用失效；未知写入按原 requestId 查结果，不盲目重写。

## 实现四：一处共同指导，各项目只写差异

1. 建立一份可维护共同来源：用户语气/不确定性、记录粒度/落点、阅读与写回边界、行首格式、少量风格正反例。
2. 各工作区引用同一来源或生成带版本副本；项目只补充差异。记录此次实际加载版本，不要求多文件夹手工复制共同文本。
3. 修改一处后，新读取能采用新版；旧现场知道当前加载版本并可重读。不承诺普通文件/软链接会被任意 Agent 自动加载，或当前会话自动更新。
4. 给实际支持的 Agent 入口短而可用的说明/模板；具体产品配置核对真实加载机制与官方资料。不覆盖用户全局配置，不写入 Codex 记忆。
5. 用户明确编辑共同指导时才改长期来源，局部要求不自动提升为所有项目规则。

## 实现五：材料引用、内聚记录与真实写回

1. Agent 在本次任务许可的工作目录写实际文件，复用现有文件/材料输出边界。自然材料通道不变成任意全盘写接口。
2. 复用 A 的真实解析/关联结果取得 materialId、当前文件名和完整 reference，已有身份不重复登记。并行期间先用基线已有关联/材料读取结果，不复制 A 算法。
3. “详见 + 文件名链接”直接使用服务返回的稳定 reference，不猜路径、不造 UUID、不用 wiki 链接替代；机器可读结果不依赖剪贴板。
4. 补充、格式整理、允许的结构变化调用既有 content.read/apply/result/recover/retry 与 Journal，记录目标落点、基础版本、实际作者和范围；并发编辑不得被旧提议覆盖。
5. 同请求/阶段重试幂等。真实进展续接现有问题/任务，产物放材料，初期讨论只留下值得再使用的想法与权衡。
6. 仅编排只改方案；用户要求补充/整理才写回，明确要求改写时按指示进行。原句限定、理由、思考变化和重复来源不擅自消除。

## 实现六：获授权的普通 TODO

这是新增能力，不通过放宽旧正文校验伪装实现。

1. 普通 TODO 权限独立于读取、编排、正文/文件写作。用户通过真实本地受信入口明确允许当前工作的目标范围、操作与生命周期；外部 payload 不能自授权。
2. 已获准范围不反复弹小确认；执行前仍核验身份、版本与完成依据。范围切换、重绑定、撤销后许可失效。
3. 按实际执行/核验事实维护状态，保留简洁依据/材料链接；子步骤完成不推断项目完成，想法和问题不自动变 TODO。
4. 正式任务/事务、受管字段、程序及阶段认可走正式端口。自然替换不能修改这些内容，Agent 不代用户认可。
5. 权限不足、范围外、冲突、部分成功、Journal 未确认和未知结果准确处理，未可靠完成不能提前 DONE。

## 行首格式

所有新写作语义标记用 `**[目标]**`、`**[想法]**`、`**[注]**`、`**[记录]**` 等，遵守共同约定。普通待办仍为 `TODO 核对取消条款`；不新增正式 [任务]/[事务]。已有正式锚点/受管字段复用 canonical-writing 和正式路径。TODO/DONE 不加粗；旧裸标记可读取。

用户明确要求整理现有格式时，展示受限真实差异，保留措辞、UUID、层级、属性、任务状态。代码、引文和句中字面标记不误处理；只换读法不顺便写回格式。

## 三条真实协作演练

- **边做边记录**：读真实现场 → 写比较文件 → 取稳定引用 → 续接原任务 → 记有意义的阶段变化 → 有权限/依据才维护普通 TODO。原项目仍保留未决定、未完成内容。
- **讨论后谨慎沉淀**：多轮合成讨论只沉淀必要想法/条件/权衡，续接同主题；保留“可能/目前偏向/尚未询问”，可靠重试不重复，只有确实要做的动作才形成 TODO。
- **零散记录再协作**：重复句、半句话、问号与新条件 → 两种读法，原文不变 → 明确要求才整理实际格式 → 用户同时加一句使旧提议过期 → 重读继续，用户补充仍完整在场。

使用真实本机 CLI、插件、Graph、文件及 Journal，不只跑模拟 router。再验证两工作区加载同一指导，新版本重读；未授权 TODO 拒绝、授权后有据执行，正式对象仍受保护；断连后查询与幂等恢复。

## 最终跨模块验收

准备共用合成资料：不少于 80 块、约 4,000 中文字符、三至四层关系的原文；普通 TODO/正式边界、重复句、未知/裸/加粗标记、条件/反例、表格/代码/引文和材料链接；两个材料根、同名文件、嵌套目录及五类中文文件。不使用用户生产资料。

| 路径 | 必须核验 |
| --- | --- |
| 文件系统加入文件 → 材料区 | 自动出现一级项，逐层进入/返回，同名身份不串；无 Agent 也可用 |
| Agent 产物 → 引用 → 笔记 | 同一真实 ID，完整文件名 reference，续接原落点，重试不重复 |
| 原生/正文引用 → 预览 → 独立窗口 | 五类核心文件可读，目标/版本一致，原件字节/草稿/书签保持 |
| 两读法 ↔ 原结构 | 逐来源核对全文/上下文，原 Graph 内容/层级/版本不变 |
| 点正文/标题 | 真实来源集合与后代准确；文本选择可用，文件点击不触发高亮 |
| 用户同时写原文 | 过期方案/写回失效，草稿/光标/条件/新补充保持；重读后继续 |
| TODO/正式对象 | 普通任务授权与依据真实；子项不推断整体完成，正式程序/认可不越权 |
| 共同指导 | 一处更新、两个入口实际重读同新版，项目差异不丢；旧版本可识别 |
| 改名/失联/范围切换 | 可靠 ID 和旧引用保持；晚到结果不串工作，窗口/监听释放 |
| 最终安装包 | 仓库外解压运行，格式资源/worker/通道可用，不依赖开发路径或 Lab 注入 |

加必要来源集合、完整性、版本、权限、落点、格式、幂等/恢复与生命周期回归。至少执行 `npm run check`、`npm run package:plugin`；最终安装包解压实例重跑核心闭环，记录包与实际运行文件身份/hash。

所有通过附实际事实；未知、未接线、只有 HTML/解析器/假回执不算通过。未实测物理 IME、Finder、剪贴板、平台/宿主版本及普通 IO 竞态如实列出。A 尚未可得时继续独立工作并准确列出最终联调依赖，不能提前宣称整项完成。
