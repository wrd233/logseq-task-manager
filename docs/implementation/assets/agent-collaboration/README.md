## 用它观察什么

三个情境使用同一个合成旅行项目：边做事边记录、讨论后谨慎沉淀、零散笔记逐渐整理。每个情境有六步，可以看原生笔记、工作台阅读、材料、历史、协作现场与共同指导如何发展；可以切换读法、定位来源、观察原文变更后旧提议失效，以及两工作区重新加载指导版本。

界面借用真实工作台的暖灰、纸面、青绿色与紧凑导航，并模仿 Logseq 原生块编辑的外观。它不连接真实 Graph、不读写用户文件、不启动外部 Agent。

## 演示和实际需求的区别

这是讨论参考，不是新功能已经实现的证明：

| 演示表达 | 两分支仍须真正实现和验收 |
| --- | --- |
| 材料条目与展开预览 | 真实目录自然同步、五类文件解析、原生引用路由、独立窗口 |
| 读法与来源箭头 | 可组合 Agent 方案；直接点正文/标题的真实 Logseq 来源集合高亮 |
| 发展步骤中的笔记/任务变化 | 真实 Agent 通道、限定范围写回、Journal、普通 TODO 许可与完成依据 |
| 共享指导与版本刷新 | 一处维护来源、实际 Agent 入口、两工作区加载与重读版本 |

演示里的阅读分组、表格、反馈和窗口是合成数据。最终格式、权限、身份、版本和完成口径以两分支共同约定为准，不能把演示中的箭头或模态预览当作完整需求的上限。
