## 使用路径

1. 重载本分支构建的 Logseq 插件，工作标题旁点击“简报”，或点击顶部“简报”。
2. 左右按钮／方向键浏览工作；逐段展开“来源”，也可查看完整原始记录、定位原块或恢复工作。
3. 尚未生成时，点击“在 DSH 生成简报”，进入对应工作对话；在 DSH 工作面板点“写工作简报”，发送追加的草稿请求。已有连接与 Agent 配置继续沿用。
4. Agent 通过已有 reading 工具提交后，回到简报窗口读取。原文变化时旧简报有明确提示，可再次生成。

## 当前限制

- 使用同一 Logseq 插件 profile 的现有本地读法存储，未实现跨机器简报同步。
- 独立窗口是宿主内模态阅览浮窗，可关闭回到原页面；不是独立系统窗口。
- 当前简报逐段追溯到本工作原始块。尚无后台静默生成、多情境选择、跨工作历史检索或外部材料逐句引用。
- 真实 Desktop Graph、DSH 原生输入插入与远端模型端到端仍需安装本分支产物后体验。合成示例用于阅览和通道检查，不是实际模型产出。
