## 当前可用行为

- “材料”收敛为“文件／目录”两页，去掉搜索、加入材料按钮、文件路径输入和独立收纳文本表单。
- 未关联目录的工作首次保存时，在默认根下创建专属目录；多个材料目录各自绑定，单选默认保存位置。加号调用宿主目录选择器，添加已有文件无需分类或命名。
- 拖入文件复制到默认目录并保留原件，文件夹保留文件的相对结构。名称同步出现，逐项显示等待／处理中／结果，失败可按同请求重试。列表按完成结果刷新，不预读每份 Markdown 全文。
- 单击材料名阅读或外部打开；行末菜单改名、直接复制链接，拖出保留稳定引用。没有把双击与立即打开叠加。
- 启用既有长文本设置后，原生粘贴达到阈值出现一次文件名和收纳决定。取消保留原文；确认落盘后，仅在原编辑元素和内容仍匹配时替换粘贴范围。
- 稳定 ID、旧全局记录、UUID 文件、longdoc 引用、原文恢复、授权编辑、冲突草稿和多工作关联继续使用既有核心。新增 `materials.import` 与用户拖入复用文件导入能力，不隐式写正文引用。

具体操作见[产品设计](../design/materials-module-design.md)，权威、数据格式、五幅流程图和真实 API 示例见[架构](../architecture/materials-module-architecture.md)。

| 行为 | 实际证明与限制 |
| --- | --- |

| 一次点击复制链接 | 点击材料操作中的复制，宿主浏览器读取与系统剪贴板读回均为完整 longdoc Markdown 链接，包含中文与图标 |
| 多目录与选择默认 | 加号真实调用宿主选择接口；隔离启动器预置返回测试目录，已有 Markdown 登记并保持原位置，两个目录可选，默认切到手选目录。OS 原生选择器的人工操作未验 |

## 未覆盖的边界

Finder 的实际鼠标文件夹拖放、OS 原生目录选择器的人工操作、真实中文 IME、完整原生 Undo 链、双 Graph 原生切换、其他 Logseq／平台、断电与长期 soak 未实机验收。本轮没有重新进行真实并发 Markdown 冲突链；既有版本、草稿和 Graph 保护由完整自动回归验证，较早实机链见原材料模块验证记录。

普通 IO、rename、Web Locks 和读回不是跨进程原子比较交换。二进制由宿主复制、类型和大小核验，核心不提供二进制全文版本或逐字节读回 API。只保留文件相对结构，宿主仅返回文件时不保证空嵌套目录、权限或其他文件系统元数据。一次目录操作有 1000 项／24 层限制，没有全面监听、全盘搜索或任意移动识别。普通未持久 UUID 的 Logseq 块重新建索引后的工作目录恢复仍受既有来源身份限制。

材料接口可在插件上下文真实调用，未新增外部进程完整材料服务。新增材料目录不代表正式 Workspace 主目录，也不扩展 agent 权限、阶段或主动行动建议。
