# MiniProject Formal / Natural Boundary

## Formal current state

- WorkObject identity, kind, lifecycle, engagement, WaitingCondition, current focus, version
- MiniProject WorkIntent: nullable desired outcome and optional completion checks
- PrimaryAnchor registered managed-field UUIDs

Formal changes use closed operations, optimistic preconditions, durable Commit stages, GraphEffect verification, Undo, and Recovery.

## Natural content

`[当前状态]`, `[背景]`, `[资源]`, `[支撑交付物]`, `[结果]`, journals, source wording, and history remain Logseq content. Agent diagnosis may read them but the Kernel does not claim them as business state. Phase 7 can only add a reference through typed curation.

`[核心输出]` and `[完成标准]` are managed WorkIntent presentation and cannot be written through natural curation. Labels are not identity; PrimaryAnchor UUIDs are. Historical intent is preserved as source material when current WorkIntent changes.
