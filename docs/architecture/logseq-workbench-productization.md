# Logseq 工作台产品化：实现分工与身份恢复

2026-11-20，基线 `codex/logseq-agent-article-reading` 的 `395315f`（阅读策略 `33cb360`）。产品决策见 [D-32～D-35](../product-design/DECISION-REGISTER.md)，阅读契约继续使用 [ReadingPlan](../design/reading-plan-contract.md)。

## 一个工作面，不是另一套工作模型

| 用户操作 | 实现归属 |
| --- | --- |
| 单一工具栏入口、找工作、当前工作、其他 | `index.ts`、`host/panel-host.ts`；共用原 FeaturePanel 的切换/关闭/宿主布局 |
| 搜索已有工作和所有可查页面、最近工作 | `catalog-local.ts`、`catalog-publisher.ts`、`catalog-view.ts`；本地搜索不要求收录，也不扩大 DSH 发布范围。私有收录/排除记录仍保留 |
| 当前工作及文章、材料 | `work-view/controller.ts`、`shell.ts`；正文与材料共用标题，临时原生页面由浏览提示区分，不改变工作 scope |
| 直接原文或渐进文章 | `report-controller.ts`、`renderer.ts`、`progressive-reader.ts`；UI 不再改变 report/structure 模式。既有非文章阅读计划和原接口仍可读，旧成果在版本选项，原结构在 Logseq 或 DSH |
| AI 助手与候选 | `reading-ai.ts`、`reading-controller.ts`；同一输入栏处理提问、整理与有明确原块的改写。复用现有邀请、模型、后台 Agent、候选与采用核验 |
| 材料搜索和预览 | `materials/controller.ts` 以及已有 MaterialService、MaterialTransfers、MaterialPreviews。名单包含工作关联材料、显式来源和关联笔记；全文预览仍由原文件读取器完成 |
| DSH、阶段、正式确认、授权 | 现有 workspace/agent/stage/task 模块。UI 入口下沉，契约、执行器、正式数据和许可不因界面收敛改变 |

全局「当前工作」及工作内「文章」返回同一阅读所有者；材料列表、文件预览和原生参考页都是浏览位置而非新工作。工作切换须由搜索选择、原生明确打开页/块或上层工作动作决定。书签仍由真实 renderer 捕获，原生输入/组合事件保留宿主控制；覆盖态先让出原生编辑空间，输入未完成时不切换回来。

### 文件 Graph 冷启动

- **区分工作接续身份和实时来源身份。** 文件 Graph 的页面 UUID 可在重新索引时改变，实际冷启动还可能先返回之前缓存的 UUID，随后索引才换成新 UUID。原持久化书签以 Graph + 页面名保存；`workspace/page-identity.ts` 复用这个真实页面入口，保存已解析过的本机页面 ID 别名。当前工作刷新时核对同名页面的实际 UUID，在当前面板导航仍有效且未在本工作原生写作或组合时自动接续；不会以原生临时浏览位置作为查询对象。块 scope 仍严格使用实际块 UUID，不按标题猜测任意块。不同 Graph/不同页面名称不会合并。页面改名、删除后重建、无持久 ID 块跨重建并非普遍身份恢复承诺。
- **文章与现场。** `ReadingViewStore` 先使用当前页面记录，再沿同一页已知 ID 找上一份记录，旧 UUID 下的存储不删除。已有文章的文字与语义展开键、书签、历史快照保留。只有整个已保存正文森林的可用性、顺序、深度和实际内容完全一致，且发生页面 UUID 重建时才重接实时来源 ID、版本及文章脚注（旧存储记录仍保留）。树不同则保留旧依据、显示变化，不能把不明原块冒充当前来源或自动采用候选；全部当前原文仍可读。普通原文书签找不到旧块 UUID 时只使用保存的滚动位置作近似返回。保留最后的实际阅读焦点，而不是关闭按钮或脚注数字作为停点文案；启动时若宿主仍有独立原生输入，保留语义锚点，不夺取输入焦点，显式重开后恢复。
- **材料与目录。** 目录查找和材料关联索引认得同一已解析页面的本地别名；原材料记录及文件不搬迁。已存在的受管理工作目录核验相同 Graph、页面入口、workspaceId 后，更新其管理 manifest 的当前页 UUID，旧镜像版本留存；CLI/DSH 继续要求 manifest 与真实连接的 scope 一致。显式关联笔记仍以已保存关联作为身份，读取时解析实际页面，笔记材料版本由真实记录内容与原顺序决定，而非宿主瞬时页 UUID。
- **会话与权限。** DSH WorkRef 继续使用已收录页面的原标识或本机首次记录的页面身份，用于找到正确 session；新连接仍携带本次实际 SourceScope，写权限不从别名或旧连接继承。页面本身不给正文、普通 TODO 或阶段写入授权；这些操作需要实际块范围。页面关联/重启恢复不会写入 Logseq 原块、自动保存模型答案或创建正式对象。

## 视觉及生命周期

共享 `visual-style.ts` 的纸面、正文、辅助文字、强调色和边界统一菜单/搜索/AI/材料。标题区只保留工作名称及当前行为；「其他」是全局入口，当前工作和材料各自的省略菜单以当前内容为准。低频行操作悬停/焦点时显现，键盘和触屏仍可达；候选/脚注控制在工作台实际视口内。主题同步取自 Logseq 宿主，宽窄仍由原来的 `readingLayoutSpec` 决定。

模型及 DSH 不在线不影响打开保存的原文、文章及本地材料。状态提示仅在等待、变化或需要行动时呈现，权限和诊断进入设置。完整端到端验证、未验证的平台与边界见 [本轮验收](../implementation/logseq-workbench-productization-validation.md)。
