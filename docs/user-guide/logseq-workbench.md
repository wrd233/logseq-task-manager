# Logseq 工作台：从笔记继续工作

适用于 2026-11-20 的产品化预览。它不要求你先建立项目、正式任务或协作目录。

## 找工作

从 Logseq 工具栏打开「工作台」；第一次直接到「找工作」。输工作或旧笔记的名称，回车打开第一项，也可选择「阅读当前页」。最近工作里第一项保留上次读到的内容。搜索选项仍支持收录当前页、从当前块开始及调整首页的自动发现结果。收录不是读笔记或提问的条件。

## 读与写

当前工作上方显示标题，默认读「文章」。没有整理过就直接读保存的 Logseq 原文。点「写作」进入原生编辑，或从原文段落/脚注打开具体记录。宽窗原生页面与阅读并排；窄窗切到原生编辑，完成当前输入后点「返回文章」。阅读停点按工作保存；临时打开参考页不会改成另一件工作。

有整理文章时：初读看最少信息，点击带微弱下划线的词句展开细读，脚注打开就近依据；「查看原文」打开完整当前记录，也能查看整理时的依据。来源变化后点击更新提示核对。不会自动替换你正在读的文章。

## 使用材料

「材料」显示当前工作关联的文件与笔记。搜索当前材料；点文件名进入真实预览，点关联笔记在 Logseq 参阅；返回「文章」仍是原工作。从「加入文件…」选择文件，或拖入文件及文件夹，新加入的是副本。使用长文本收纳时，按原有原生长文本命令或在设置开启长粘贴询问。

「其他 → 全部材料」可在任何时候查找全局材料。全局材料的选项可关联到当前工作，不会自动把它设成新工作。材料选项里管理目录，单个文件选项里复制链接、重命名、补关联或修复位置；文件有草稿或版本冲突时会就地出现恢复操作。

## AI 与 DSH

点「AI 助手」：不填文字可直接「整理文章／更新文章」，输入文字可「提问」或「按要求整理」。选中符合条件的普通原块还可以准备改写建议。答案只读，复制、插入新块或确认替换需要你操作。已有文章的整理结果先准备候选，只有点击「采用修订」才改变当前文章；可选「后台准备修订」，也可随时关闭或取消。

需要复杂协作，点当前工作「在 DSH 继续」；它复用已有工作目录和最近的 DSH 会话，未建立目录时按实际材料位置准备。DSH 接收到当前工作、请求、依据及选段，加入对话草稿和发送由你决定。此入口需要实际运行的 DSH 和 companion（包内协作启动器）；模型暂不可用时继续使用原文、已保存文章和材料。

工作标题的更多选项：阅读成果/上一版文章、块工作的阶段记录与确认、共同指导与项目差异、手动关联/修复目录、需要时的独立写入许可、写回冲突及维护。正式任务在「其他」中按需启动，普通 Journal、TODO 与页面不会自动升级为正式任务。

## 预览与恢复

从独立分支运行 `npm run preview:logseq`，加载 `tmp/logseq-preview/task-copilot-workbench`，或解包交付 ZIP 后从 Logseq 插件页加载解压目录。核对插件设置的当前版本；原有 Graph 不需要转换。请先用独立 Graph 体验。构建身份、实际验证与限制见 [验收记录](../implementation/logseq-workbench-productization-validation.md)。
