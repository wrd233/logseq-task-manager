# 工作台使用手册

从一份普通 Logseq 工作块开始，阅读正文、加入材料、协作修订，再认可实际看过的阶段版本。工作视图、材料和阶段记录可在未开启正式任务系统时使用。

**第一次使用：** 阅读[首次准备](workbench-usage.md#首次准备)，然后跟着[连续示例](workbench-usage.md#1-建立一份工作)操作。已经配置过的用户直接从当前工作块打开工作视图，无需每天重新构建或填写连接设置。

| 想做的事 | 从这里开始 |
| --- | --- |
| 打开工作、阅读、调整显示 | [建立工作与阅读](workbench-usage.md#1-建立一份工作) |
| 找到刚放入目录的文件 | [目录文件与关联](workbench-usage.md#3-加入文件先看再关联) |
| 把长文存成材料，留下短引用 | [收纳长文](workbench-usage.md#4-把长文收纳为材料) |
| 看改动、直接纠正、写建议 | [阶段与审阅](workbench-usage.md#5-推进一个有意义的阶段) |
| 认可后继续写、查看历史 | [认可与继续](workbench-usage.md#6-认可所见版本继续自己的写作)、[历史](workbench-usage.md#8-回看历史停止连接和重新进入) |
| 围绕问题看原文依据 | [按问题聚焦](workbench-usage.md#7-按问题聚焦再恢复完整内容) |
| 连接断开、材料暂不可用、写入结果未知 | [恢复](workbench-usage.md#遇到问题时怎样继续) |
| 让外部 agent 正确接入 | [接入附录与开始提示词](workbench-usage.md#agent-接入附录) |
