# 装好后直接阅读

[下载当前验收包](../implementation/assets/simple-start-reading/task-copilot-workbench.zip)。基础阅读不需要 Node、npm、Kernel、协作服务或设置项。

当前包含材料 A 与阅读/协作 B 的合入，并修复材料页签往返丢失阅读焦点的问题。已在新的隔离实例复验基本读法和该修复，完整最终矩阵仍在进行；请先在合成或可丢弃的 Graph 副本使用，并查看[当前实施记录](../implementation/reading-and-agent-collaboration-handoff.md)。这不是重要生产 Graph 的安装建议。

## 安装与更新

1. 解压 ZIP，保留其中的 `task-copilot-workbench` 文件夹。
2. 在 Logseq「设置 → 高级」开启开发者模式。在「插件」页选择「加载解压的插件」，选中这个文件夹并启用。
3. 回到自己的原生页面。事务、任务和 MiniProject 标题旁出现「阅读」，就可以使用了。

更新时先停用旧插件，解压新包，再从插件页加载新文件夹并启用。若在原目录替换文件，使用插件页的重载或重启 Logseq。已有设置、目录与私有记录继续保留。此包通过解压加载，没有商店上架或自动更新功能。

当前隔离复验使用 macOS 15.1 ARM64、Logseq Desktop 0.10.15。较早截图来自其他阶段；Windows／Linux 和其他宿主版本未由本次验收证明。

## 写原文，点一次阅读

照常写：

```text
TODO **[事务]** 整理参考资料
    没有行首标签的正文也会完整显示。
    [注] 条件、反例、重复句和局部 TODO 都保留。

**[MiniProject]** 研究一个方案
    相关正文放在它下面。
```

点工作标题旁的「阅读」，看到该工作和全部子块的完整报告。MiniProject 不必重复写 `#MiniProject`。代码、引文中的示例和普通 TODO 不会多出工作对象按钮。内嵌事务可以明确打开，再点「返回：上层工作名」。普通段落点击、选字、输入和链接不会切走当前工作。

Project／Area 独立页面的页面标题旁也有「阅读」，读取整页实际正文。其他页面可以从命令面板选择「工作台：阅读当前页面」。整页工作可以关联自己的目录、带保存的原文去协作、设计读法及查看材料；另行允许文件写作后，Agent 可以在该目录保存产物。页面连接没有可写根块，不能维护正文、TODO 或阶段。需要这些操作时，先打开实际工作块，再建立对应的独立许可。

普通块仍可用右键「工作台：从此块打开工作视图」，或快捷键 Cmd/Ctrl+Alt+P。顶部只有一个「工作台」入口；没有明确当前工作时，会显示具名「继续阅读」，由你选择。

## 继续原生写作

正在原生输入时也能点「阅读」。输入框、草稿、光标和焦点保持，阅读显示已保存内容。Logseq 保存后自动更新，无需重新生成报告或重载插件。

「在 Logseq 写作」进入真实原块；长文中间可从段落的「⋯ → 编辑原文」进入。宽窗并排，拖动中间的分隔线调整宽度，也可用 Tab 到分隔线后按左右方向键。窄窗进入原生编辑后，点顶部「返回正文」一次返回；不用为了返回先结束输入。

正文／材料往返和关闭再开保留位置与折叠。重启在同一 Graph 中核验来源并恢复上次开闭和现场，不会为恢复自动跳转原生页面。普通输入中的中文 IME、系统拖放、剪贴板和宿主 Undo 仍需要按[本轮复验步骤](../implementation/workbench-visual-refresh-handoff.md#尚未完成的-desktop-项目与最小复验)进行人工实机核验；现有证据没有把模拟事件当成这些操作的完整结论。

## 真正需要时再加入材料

进入当前工作「材料」，直接拖入文件或文件夹。未关联目录时，该工作在默认材料根下拥有专属文件夹，首次保存才创建。根目录留空也可使用；实际位置在「目录」页查看。

「目录」页点击“添加目录”，在文件管理器中选择已有目录；可添加多个，并选择一个默认保存位置。已有资料不自动迁移，旧 longdoc 引用继续使用原位置。拖入默认复制并保留原件；失败项显示原因并可重试。明确默认目录不可用时保留内容，不暗中改存另一处。

目录按一级内容显示，单击文件夹逐层进入，用“返回上层”返回。宿主需要一次受信目录读取；已在本机复制目录时，可使用界面的粘贴读取入口。没有当前读取许可或目录失联时会说明不完整，保留已知材料和引用，不能把旧观察当成当前完整目录。同名文件仍按各自目录和实际材料身份区分。

单击文件名、正文中的材料链接或 Graph 附件链接进入统一只读预览。Markdown、DOCX、图片、PDF 和 XLSX/XLS/CSV 有内置阅读：PDF 翻页，图片放大，表格切换工作表及分页；DOC 老格式显示明确限制。DOCX 展示可解析正文、列表、表格和图片，不能承诺与 Word 分页完全一致。预览不会执行文档脚本、外链图片或表格公式。

预览中的“独立窗口”打开同一文件和版本的原生窗口，可移动、调整尺寸和放大阅读；来源变化时旧版本不能冒充新版。返回正文恢复有效阅读位置，点击文件链接不会同时触发来源高亮。目录及文件读取失败时保留历史信息，并提示重新核验。

长文本直接粘贴到 Logseq 编辑区。开启「粘贴长文本时询问收纳」后，达到阈值会提示文件名与「收纳／保留原文」。收纳完成后留下链接；位置变化时保留原文并提供已保存材料的链接。「复制链接」直接复制，单击文件名阅读，改名用“更多 → 改文件名”，在当前行保存或取消；失败保留名称草稿。复制成功在该行反馈，失败可重试。

阅读层把已知行首标记显示为目标、思考、说明、记录和问题，原句、嵌套与字面示例保持；“对照原文／查看原结构”可核对原标记。外观跟随宿主明暗主题。新版截图和验证范围见[视觉刷新证据](../implementation/assets/workbench-visual-refresh/README.md)。

## 按需协作

基础阅读和已有材料随时可用。需要外部协作时：

1. 在工作「工作选项 → 工作目录 → 关联工作目录」选择 Graph 外的实际目录。
2. macOS 运行包内 `Start collaboration.command`，保留启动器窗口。这个可选能力需要 PATH 中可用的 Node 20.19 或更高版本；基础阅读没有这个条件。现有协作通道支持 POSIX。
3. 回到这份工作「工作选项 → 外部连接与恢复 → 带当前工作去协作」，填写本次请求，选择必要背景，再点「连接并准备协作现场」。新连接仅允许读取和设计读法。程序自动发现连接文件，不用抄连接正文或块 ID。
4. 把界面生成的启动语交给你选择的 Agent。它使用实际插件中的 `dist/workspace.mjs` 和当前通道位置，先读取 `workspace collaboration read` 与 `workspace guidance read`。已有可靠会话链接会显示；没有链接时，使用你原来的 Agent 入口继续，插件不会自动新建聊天或发送消息。

协作现场保存当时的完整原文、层级、版本、所选背景、实际材料引用、阅读状态、指导版本和本次许可。原生草稿不会作为正式原文导出。读取结果中的 `scene` 是保存的现场，`current` 单独说明现在核验的来源、材料、指导及权限是否一致；不一致时先用 `workspace collaboration refresh` 重读。`workspace read` 仍是最后已知副本，不是本次现场已核验的证明。

共同指导在「共同指导与项目差异」维护。本插件实例只有一份共同来源，各工作只保存自己的差异。只有点击「明确保存共同指导」才改变长期来源；本次请求和项目差异不会改其他工作的规则。修改后让 Agent 再执行 `workspace guidance read`，记录返回的版本。旧现场保留当时加载的文本和版本，可以辨认后再重读；当前聊天不会因为来源变化自动更新。

共同来源与项目差异使用 Logseq 的插件私有 FileStorage，不修改全局 Agent 配置，也不写入 Codex 记忆。共同指导第一次读取使用随插件的默认文本，不在读取时创建文件；明确保存后读取实际存储内容。界面中的启动语提示通过 CLI 读取同一来源，现场也记录这个共同来源的身份与版本；已有用户 `WORKSPACE.md` 保持。

连接就绪只表示本机通道可用，Agent 尚未自动开始工作。需要写正文时，点当前块工作的「允许 Agent 维护这里正文」；界面明确说明当前真实块范围，并建立一份正文连接。它不授予结构整理，旧连接的文件与 TODO 许可不继承。需要调整原块位置时才用「允许润色并整理原块」。文件写作需另外点「允许 Agent 写工作文件」，材料自身的编辑限制继续有效。读取和编排不会取得这些许可。

需要 Agent 维护普通任务时，另点「允许 Agent 维护普通 TODO」，勾选可维护的段落范围和新建、完成或重新打开操作，再明确允许。范围包含其后代；本次连接内无需逐次确认，切换工作或重新连接后需重新允许。完成要读取当前材料、核验指定版本与原样依据，并在任务旁留下链接；材料片段存在仍需结合实际任务判断。正式对象和项目整体不由这个入口变更。日志会保留真实落点、版本、调用来源和本次读回的指导版本；结果不明时按原请求查回，部分成功或日志未确认都不能算可靠完成。这一新入口仍在实施验收，当前下载的旧包没有这些新增能力。

切换工作、Graph、重绑定、停止连接或卸载后，旧连接不能继续调用；回到原工作需要重新允许。已发出写入若超时或断连，先重连并按原 requestId 查询结果，不盲目另发一份。结束时在工作选项选择「停止 agent 工作连接」，并在启动器窗口按 Ctrl+C。

Logseq 0.10.9 没有允许插件任意启动本机进程的接口，因此本轮交付的是独立启动器加自动连接发现，尚未实现“插件一个按钮直接启动 companion”。已有自定义连接位置继续有效。

上方下载安装链接仍是视觉刷新阶段包。本分支新增的协作现场、共同指导和只读权限入口尚未交付最终安装包；实施与实测边界见[当前交接](../implementation/reading-and-agent-collaboration-handoff.md)。视觉刷新包的校验、截图与未验范围见[证据索引](../implementation/assets/workbench-visual-refresh/README.md)。旧版一键阅读的历史记录另见[原证据](../implementation/assets/simple-start-reading-main/README.md)。
