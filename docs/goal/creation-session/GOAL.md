# Persistent Creation Session Goal

Build a persistent, resumable, multi-session path that turns blank intent, a Block
subtree, or a normal Page into a reviewed MiniProject or Project. Before explicit
confirmation, SQLite is the only authority and Graph/formal writes remain zero. Final
creation reuses Proposal, Semantic Commit, Audit, recovery, and Undo.

The boundary excludes a general chat system, a complete Block editor, automatic
whole-Graph sourcing, Task/Area creation, automatic ownership, cross-page moves, and
any second formal write kernel.
