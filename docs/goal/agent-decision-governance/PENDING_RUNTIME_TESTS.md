# Consolidated Agent Governance Runtime Gate

Do not run piecemeal. After all automation is complete, execute one bounded Desktop session (target: at most 30 minutes) against a dedicated local page and the same SQLite authority.

## Preconditions

- exact Goal build loaded from a stable path;
- Logseq 0.10.15, Local Service READY, Doctor recorded;
- EXPERIMENT default, Agent formal writes disabled;
- before counts captured for Object, Candidate, Proposal, Commit and governance rows;
- no credentials or private raw text in screenshots/logs.

## Representative scenarios

1. Explicit Task Shadow: stable Source Root, Chinese rule, zero formal Object change, reload persistence, open source.
2. Weak signal: Review Signal only, no Candidate/Object, quiet UI, included in Review export.
3. Multi-target: LOCAL declines, bounded EXPANDED, human/review route, no duplicate Task.
4. Source revision: ordinary → action → explicit marker remains one thread with only meaningful revisions.
5. Visual matrix: Light/Dark; about 1000×720 and 760×720; empty/sparse/dense/detail/failure/pause; no overflow or enum wall.
6. Feedback: correct/mostly/wrong; compatible bulk and automatic incompatible grouping; Undo remains independent.
7. Pause/degrade: one rule and global writes paused; Shadow continues; pending execution blocked; no duplicate after resume.
8. Provider/Service failure: timeout/cancel/auth, Service restart, Plugin reload; Logseq editing remains normal and failures stay bounded.
9. Review export: Markdown + machine data, Evidence identity dedupe, source missing/truncation, no secret or unbounded Graph dump.
10. Guarded representative only after the long runtime gate: explicit user authority, existing formal chain, revalidation, apply → reload → Undo → reload, then disable writes and confirm Shadow.

## Evidence matrix

For every scenario record: exact build commit, Graph/page, runtime mode, before/after counts, user-visible result, service/Doctor result, screenshot IDs, whether proof is automated/Desktop/live-LLM, and unresolved limitations.

## Honest stop rule

If scenarios 1–9 pass but 14 days/200 Decisions are not yet accumulated, set `CONSOLIDATED_SHADOW_RUNTIME_CHECKPOINT`. Never fabricate elapsed time or treat fixtures as production accuracy evidence.
