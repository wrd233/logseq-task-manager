# 模块需求：全局态势与共视活画布

> 状态：已落地基线（`feat/personal-time-stage-v1`，Sprint 1–3 及实机验收打磨已实现并验证；受[来源与状态](../SOURCE-AND-STATUS.md)及[决策登记](../DECISION-REGISTER.md) `D-50 ~ D-63` 约束，其中 `D-62 / D-63` 为已确认待实施契约）。返回[文档导航](../INDEX.md)。

## 1. 目标与定位

在既有「单工作现场（Logseq 阅读写作 + 单工作强边界协作）」之上，补齐**“抬头看路（Zoom-Out）”的全局态势与时间节奏层**：

- 做完一项具体任务后，可从当前节点平滑拉远镜头，直觉感知长期责任领域（Area）的四态角色（主线 / 支线 / 维护 / 搁置）、近期脉搏与真实错配；
- 在同一悬浮活舞台内完成**三视角切换**（`季节星区 | 本周容器 | 今日容器`），将顶层注意力顺滑落入纯语义有限时间容器（详见 [07-个人规划.md](07-个人规划.md)）；
- 顺手扫视右侧可折叠 **Inbox 浮带**（聚合 iPhone 快捷指令「随口记」iCloud 语音碎片与本地个人 Inbox），悬停 0ms 照亮归属、拖拽安放或批量交由 Agent 梳理；
- 将全局态势与时间容器经由**Agent 无关的本机 Companion MCP** 共享给任意外部 Agent（Antigravity / Codex / Claude Code / DSH），配合 `skills/attention-navigator/SKILL.md` 实现**共视、虚态推演、人拍板凝固**。

核心分工原则（`D-50`）：**人做导演，Agent 做参谋与舞美**——人在画布上只保留极简高频动作（切换视野、点击变焦、选中指代、轻拖定方位或安放 Inbox、拍板留删）；冷启动建模、错配诊断、语音分流与周期装盒由 Agent 承担。

## 2. 载体形态与三视角顶栏

悬浮活舞台支持三种宿主持久接入，同源驱动于 `@task-copilot/stage-runtime` 与本机 Companion SSE（`/stage/events`）：

1. **Logseq 锚定浮层**：从 Logseq 当前工作顶栏「拉远」呼出；点击「开始专注」后浮层退场，仅在 Logseq 顶栏保留一行安静的正向专注计时胶囊（`已进行 Nm`）。
2. **DSH 独立悬浮窗**：支持静默边缘胶囊（Peek）/ 可拖拽缩放悬浮窗 / 全景鸟瞰三态切换（`Cmd/Ctrl+Shift+G`）；在顶栏按钮、浮窗标题栏与边缘胶囊上实时显式标注 `Agent 共视中 · 当前层次与对象`（如 `L0 季节星区` / `L1 运维能力` / `L2 项目-海丝` / `今日容器`），收为胶囊时仍保持与 DSH Agent 的实时共视并在每轮对话 `system-prompt/assemble` 前自动拉取最新视口（含精确层次、`areaId`、`projectWorkKey` 与目录），仅点击关闭（`✕`）后彻底卸载零上下文开销。
3. **独立浏览器窗（`/stage/app`）**：由 Companion 同源托管，可并排摆放在 Codex 终端或 Antigravity 旁实时共视。

顶栏保持克制，仅提供：
- 三视角切换：**`季节星区 | 本周容器 | 今日容器`**；
- **`在 DSH 讨论当前画面`**（Logseq 内无论处于 `L0 / L1 / L2 / L3 / 本周 / 今日` 哪一层，均经由 Companion `/plugin/stage/open-dsh` 直接拉起前台浏览器并携带 `#stage-discuss=1`，按 `D-62` 自动切入「全局导航台」工作区的本周自动会话并展开 DSH 悬浮星图进入实时共视，零复制粘贴、不依赖单工作绑定、不串入旧项目上下文；DSH 内直接引用进当前对话输入框；Antigravity / 外部 MCP 宿主通过 `stage_get_view` 同源共视）；
- 右侧折叠计数按钮 **`Inbox · N`**（不闪烁催办）。

### 2.1 星图与事务专属工作目录的一体化直跳（`D-60`）

承接既有单工作「一事务一文件夹 + DSH 直接以该目录为工作区」的思想，星图各层不再制造割裂的复制粘贴：
- **Area 级（L1 顶卡）**：若对应 Logseq 存在显式 `Area` 页（如 `Area/运维能力`），可直接点「**在 DSH 打开此领域**」或「**领域原文**」，自动准备/复用领域工作目录并跳入 DSH；
- **Project 级（L1 卡片 / L2 主干 / L3 入口）**：直接提供「**在 DSH 打开**」（通过 `ensureDshWork` 准备或复用该 Project 的专属文件夹并建立只读授权、直切 DSH 对应 Session）与「**Logseq 原文**」；
- **嵌套子对象级（L2 原生子对象分支）**：每条原生嵌套子事务/MiniProject 同样提供内联「**在 DSH 打开**」与「**原文**」，方便直接把 Agent 工作区缩小到单个子任务文件夹。

### 2.2 全局共视导航台工作区、自然周自动会话与 Logseq 复盘沉淀（`D-62`，已确认待落地）

为消除“全局共视浮窗寄生于先前残留单项目工作区/测试会话”引发的上下文串味（`logseq-workbench:current` 与 `logseq-stage:viewport` 同轮叠加）、`cwd` 错位及对话历史归档混乱，确立以下双轨组织与实施契约：

#### 1) 双轨空间分离与入口路由规则
- **轨道 A · 顶栏「在 DSH 讨论当前画面」→ 专用「全局导航台」工作区**：
  - 无论当前星图停在 `L0 季节星区`、`L1 领域切面`、`L2 项目结构树`、`L3 执行入口`、`本周容器` 还是 `今日容器`，点击顶栏「在 DSH 讨论当前画面」一律路由至专用的**「全局导航台」工作区**，采用“相对聚焦当前画面、但保持全局参谋站位”的视角；
  - 该工作区下的会话**绝不绑定单工作 `WorkRef`**，不写入 `BindingStore`，因此 `system-prompt/assemble` 仅注入纯净的 `logseq-stage:viewport` 与 `stage_* / time_*` 工具，不会叠加任何旧项目的 `logseq-workbench:current`；
  - 视口（Viewport）是瞬态目光，会话（Session）是持续议事：**星图内自由变焦或切换视角绝不自动切换 DSH 会话**。
- **轨道 B · 节点「在 DSH 打开 / 进入此工作对话」→ 显式下潜具体事务工作区**：
  - 讨论需要深入阅读具体项目的 Logseq 原文、本地文件或执行改动时，由用户显式点击星图卡片上的「在 DSH 打开 / 进入此工作对话」（沿用 `D-60`），切入该项目/领域/子事务专属的工作区目录与会话，浮窗自动收为边缘胶囊（`peek`）。
- **原地借景保护（DSH 内 `Cmd/Ctrl+Shift+G` 或顶栏 `◎ 星图`）**：
  - 当用户已在具体项目工作区干活、在 DSH 内自行呼出星图悬浮窗时，**绝不自动切换当前工作区与会话**；
  - 浮窗标题栏在当前会话非全局导航台会话时，可展示克制的轻量按钮（如「切到全局导航台」）供用户显式上浮。

#### 2) 全局导航台工作区目录与 Logseq 原生 Page 沉淀
- **默认目录选址**：指向当前活跃 Logseq 文件型 Graph 下的专属子目录 **`<graph.path>/pages/stage-reviews/`**（目录不存在时自动创建）；支持通过环境变量 `TASK_COPILOT_STAGE_WORKSPACE_DIR` 或插件配置显式覆盖；当运行于 DB Graph、离线或无法获取有效本地 `graph.path` 时，安全回退至 `~/.task-copilot-workspace/stage-workspace`。
- **物理隔离与隐私边界**：
  - 该子目录仅作为中立的全局复盘与规划档案柜，不包含项目源码、凭据或其余笔记；DSH 全局工作区的 `cwd` 锁定于此子目录（严禁指向 Graph 根目录或 `pages/` 根）；
  - Agent 在系统提示中明确约束：仅限在当前复盘子目录内读写复盘/规划文档，禁止越界探测或修改 Graph 内其他 Markdown 文件，继续严守 `D-41 / D-47` 隐私与授权边界。
- **Logseq 一等公民 Page 约定（已实机验证可识别）**：
  - 借助 Logseq 递归索引 `pages/` 子目录的特性，沉淀文档直接以 Logseq 原生三下划线命名空间与 `- ` 大纲体落盘，单真值原生可读、可全局搜索、可双链/反链且随 Graph 跨电脑同步：
    - 周复盘：`复盘___YYYY-Www.md`（Logseq 呈现为页面 `[[复盘/YYYY-Www]]`，顶部属性如 `type:: 周复盘`、`week:: YYYY-Www`，正文以 `- ` 大纲层级组织，可自然引用 `[[Area/...]]` 与 `[[项目名]]` 形成反链时间线）；
    - 季度星图沉淀：`季度星图___YYYY-Qq.md`（Logseq 呈现为页面 `[[季度星图/YYYY-Qq]]`，顶部属性如 `type:: 季度星图`、`quarter:: YYYY-Qq`）；
  - **严禁**在这些沉淀页中写入 `PARA:: [[PARA/Area]]` 或 `PARA:: [[PARA/Project]]` 属性，防止 `catalog-local.ts` 将复盘文档误采入星图；
  - 协作分工防并发冲突：由 Agent 负责按规范落盘或先读最新磁盘内容再追加，用户在 Logseq 中阅读与事后批注，避免双端同时编辑同一文件及手工改名导致 Logseq 迁回 `pages/` 根。

#### 3) 按自然周零维护自动会话拆分
- **确定性规则**：在「全局导航台」工作区下，按当前本机日期的 ISO 自然周（`YYYY-Www`，例如 `2026-W47`）自动对应 1 条本周默认主会话，默认标题为 **`YYYY-Www · 全局导航`**。
- **复用与自动翻新**：
  - 同周内（周一至周日）每次通过「在 DSH 讨论当前画面」或「切到全局导航台」进入时，检查轻量索引（如 `~/.dsh/logseq-workbench/stage-sessions.json`，独立于单工作 `BindingStore`）记录的本周 `sessionId`；
  - 若该会话仍存在、未归档且其 `cwd` 与当前解析的全局导航台目录一致，则直接复用；否则自动在全局导航台工作区下新建本周会话并更新索引；
  - 跨入新一周自动翻新干净会话（Agent 按需读取目录内上周 `复盘___YYYY-Www.md` 接续上下文，零手工清理负担）；
  - 用户随时可在该工作区手动新建专题会话（如季度冷启动），不影响每周默认会话路由。

#### 4) 跨模块接线与实施要点（供 Codex 落地参考）
1. **Logseq 插件 (`apps/logseq-plugin`)**：`stageOpenDsh` 调用 `/plugin/stage/open-dsh` 时透传当前 Graph 的本地路径（`graphPath`，来自 `(await logseq.App.getCurrentGraph())?.path`）及可选 `graphId`；并在 `catalog-publisher` / 正常初始化时可同步上报活跃 `graphPath` 给 Companion 缓存。
2. **Companion (`apps/task-copilot-cli`)**：`/plugin/stage/open-dsh`（及供 DSH 查询的只读路由如 `/stage/workspace` 或扩展 `/stage/state`）校验并解析全局导航台目录（优先配置/环境变量 → 当前活跃文件型 Graph 的 `<graphPath>/pages/stage-reviews` → 回退 `~/.task-copilot-workspace/stage-workspace`），按需安全创建目录，并返回解析结果及 `#stage-discuss=1` 跳转地址。
3. **DSH 插件 (`apps/dsh-plugin`)**：
   - 在 `stage/host.mjs`（与 `index.mjs`）新增串行化 RPC（如 `stage-enter-global`）：解析全局目录 → `workspaceController.create({ path: stageDir })`（首次创建命名为「全局导航台」）→ 按 ISO 周查/复用/新建 `YYYY-Www · 全局导航` 会话（绝不写入单工作 `BindingStore`）→ 返回 `{ sessionId, weekKey, directory, created }`；
   - `floating-window.jsx` 收到 `#stage-discuss=1` 时先调用 `stage-enter-global` → `ctx.sessions.refresh()` → `ctx.uiWorkspace.openSession(sessionId)`，随后展开悬浮星图并同步当前视口；
   - `Cmd/Ctrl+Shift+G` 与顶栏 `◎ 星图` 保持原地打开不切会话；当当前激活会话不在全局导航台目录时，浮窗标题栏提供轻量「切到全局导航台」按钮触发 `stage-enter-global`；
   - 当会话 `cwd` 等于全局导航台目录且处于共视态时，在 `logseq-stage:viewport` 提示中补充全局导航台身份、复盘目录写盘规范（`复盘___YYYY-Www.md` / `季度星图___YYYY-Qq.md`、Logseq `- ` 大纲体、禁止越界改其他 Graph 文件）以及“深入单项目请引导点击星图卡片切换工作区”的指引。
4. **Skill 同步 (`skills/attention-navigator/SKILL.md`)**：在剧本 A（季度冷启动）与剧本 B（周日复盘）补充落盘至当前复盘目录的 Logseq Page 命名与大纲格式约定。
5. **验收标准**：
   - 曾停留在任意旧项目/测试 MiniProject 会话的 DSH，在 Logseq 任意星图层级（L0 / L1 / L2 / 本周 / 今日）点击「在 DSH 讨论当前画面」后，自动切至「全局导航台」工作区的本周会话，左侧不再停留在旧项目，`system-prompt` 无旧项目 `logseq-workbench:current` 串味；
   - 同周内二次点击复用同一会话，切换系统时间/周键或归档旧会话后自动创建新周会话；
   - 在具体项目会话内按 `Cmd/Ctrl+Shift+G` 拉出星图不切走原会话，点击「切到全局导航台」才上浮切换；
   - 在星图卡片点「进入此工作对话」仍正常下潜到项目专属工作区；
   - 全局导航台目录默认位于 `<graph.path>/pages/stage-reviews/`（离线/无 `graphPath` 时安全回退），写入 `复盘___YYYY-Www.md` 后在 Logseq 中识别为 `复盘/YYYY-Www` 且不污染星图工作目录。

## 3. 四态星区、工作/生活边界与四档语义变焦

### 3.1 季节星区四态模型（`D-56`）

每个顶层 Area（硬控 **4–7 个**）维护轻量四态角色 `focusRole` 与轻度领域边界 `domain`：

| 字段 | 可选值 | 规则与视觉表达 |
| :--- | :--- | :--- |
| `focusRole` | `main`（本季主线） | 严控 1 个，居中微光；记录 1 句 `quarterGoal` 与 1 句 `antiGoal` |
| `focusRole` | `side`（支线） | 常规 2–3 个，承接阶段性并行工作 |
| `focusRole` | `maintenance`（维护模式） | 记录每周最低底线 `weeklyMinimum`，静默保底，**永不报变冷或焦虑提醒** |
| `focusRole` | `parked`（主动搁置） | 移入底部边缘休眠区，随时可一键唤醒 |
| `domain` | `work` / `life` | 工作与个人成长为主线；生活领域一并纳入，以低饱和左边界与极简标签轻度区分 |

### 3.2 四档语义变焦、原生嵌套与多父级归属（`D-60`）

| 镜头层级 | 屏幕主要呈现 | 刻意隐藏 / 弱化 | 核心动作 |
| :--- | :--- | :--- | :--- |
| **L0 季节星区** | 活跃 **Areas** 领地（防重叠双列网格、动态画布高度，带四态标签、脉搏、错配提示与前 3 项核心 Project）；底部文档流「搁置 / 休眠 / 暂放未归类」栏与一键「整理排布」 | 超过 7 个的其余显式 Area、长期静默支线与主动搁置 Area 退入底部休眠栏（可随时一键唤醒）；已归档页面与底层零碎 TODO 隐藏 | 任务收尾后抬头看路；拖动「⋮⋮」固定老家坐标；悬停 Inbox 照亮归属；点击推近 |
| **L1 领域切面** | 当前 Area 英雄卡（含四态角色、工作/生活切换、领域级「在 DSH 打开」）、主归属 **Projects** 卡片（语义清洗后的 1–2 行摘要 + 次归属标签 + 快捷「在 DSH 打开」）、底部的「**跨领域关联**」只读轻分区、领域轻量推进项 | Project 页内的子块收束进 L2，不在 L1 刷屏；无关领域缩成顶部极简邻域按钮；右侧 Inbox 自动上浮本领域共振条目 | 观察领域推进与停滞；通过跨区投影发现多领域协同；直跳 DSH 或就近收编 Inbox |
| **L2 事务结构** | 当前 Project 主干卡（含目录状态、次归属跳转、「在 DSH 打开」「Logseq 原文」「久别重启」）+ 右侧双段分支树：**原生嵌套子对象**（默认展示前 6 项，其余折叠，每条支持直跳 DSH / 原文）+ **轻量推进项与 Agent 虚态推演** | 其他项目收束在顶栏路径中；原始 Logseq 大纲路径与 Markdown 模板词经清洗不直接裸露 | **人机共编黄金层**：查看原生嵌套、直跳子对象目录、观看 Agent 生长虚态分支并拍板留删 |
| **L3 执行入口** | 单项推进说明 + 显式出口：「在 DSH 打开」/「回到 Logseq 原文现场」/「写入 Logseq TODO」/「标记完成」 | 不在悬浮画布内重造大纲编辑器 | 选定下一步后无缝回到 Logseq 或 DSH 专属工作区 |

### 3.3 显式 PARA 领域优先、唯一主归属与小字语义清洗（`D-60`）

- **显式 Area 优先与归档过滤**：`catalog-local.ts` 与 `CatalogWork`（可选 `parentAreas`、`lifecycleState`）原生识别 Logseq 中的 `PARA:: [[PARA/Area]]`、`PARA:: [[PARA/Project]]` 与 `Areas:: [[Area/...]]`，自动过滤 `PARA/Archive` 及 `archived / done / completed / cancelled` 页面与内部块；冷启动检测到显式 Area 时优先按真实 Area 建构 L0（生活类领域自动归为 `domain: "life", focusRole: "maintenance"`），散落条目仅按领域与活跃项目的区分主题词保守匹配，杜绝因图谱名或「整理 / 平台 / 调研」等泛词错误粘连。
- **唯一主归属 + 跨领域投影（多上级处理）**：当一个工作对象同时标注多个上级 Area（如 `Areas:: [[Area/运维能力]] [[Area/AI 自动化能力]]`）时，取首位作为**唯一主归属（Primary Ownership）**，统计数、活跃脉搏与主线错配判定仅计入主归属名下（绝不重复计数）；其余上级作为**次归属关联**，在主归属卡片上显示可点击的 `另关联：xxx` 标签，并在次归属 L1 的「跨领域关联」虚线分区中呈现只读引用卡，点击进入**同一 Project L2、同一工作目录与同一 DSH Session**。
- **卡片小字语义清洗**：通过 `formatWorkSubtitle` 剥离图谱名、`Daily Note` / 时段标题、`**[旧项目内容]**` / `**[资源列表]**:<...>` / `**[推进结构]**` 等容器模板与 Markdown 标记；Project 页展示 `状态 · 含 N 项子事务 · 已绑定目录`，子事务与日记项仅保留最末 1–2 个有效语义位置并做两行截断。

## 4. 多入口随想三口袋与 Inbox 双向共振浮带（`D-52`、`D-55`、`D-63`）

- **四入口单真值汇入与实测纠偏（`D-63` 已确认待实施）**：
  - **iPhone 语音捕获（已落地 `D-55`）**：Companion 增量监听 `~/Library/Mobile Documents/com~apple~CloudDocs/TaskCopilotInbox/*.md`，解析 `yyyyMMdd-HHmmss.md`，自动去重 iCloud 冲突副本；
  - **Logseq 每日日记单真值投影**：复用 `catalog-local.ts` 只读投影近 30 天 Journals 中以 `TODO` 或任意 `**[xx]**`（含默认标记 `**[注]**`）开头的未完成块——**行首标记仅作召回信号，正文时间死线与外部承诺语义权重绝对高于前缀**，严禁因默认 `**[注]**` 将硬承诺误投挥发池；普通流水账零噪音留在日记，已带 `[[项目]]`/`[[Area]]` 链接且无死线承诺的纯笔记归位至背景共鸣流 Feed；
  - **Agent 对话零打断泊车**：新增 MCP 原语 `stage_capture_inbox`，Logseq 在线时免弹窗经插件 API 追加一行至今日 Journal 并以 `captureId -> blockUuid` 防回声去重；离线时先落盘 `stage-pending-journal.json` 即时可见，上线后自动幂等补写；
  - **Flomo PRO 官方 MCP**：对接 `https://flomoapp.com/mcp`，**不强依赖用户手动改打 `#inbox` 标签**；短时（如 30 分钟内）或同主题连发的 `>= 2` 条递进思考自动聚合成 1 张「演化线程卡」直入「随手想法」高亮「正在发芽」，单条孤立慢思考留作背景共鸣流（Feed，零待办计数压力）。
- **三口袋大白话分治与全局流转台账（`D-63`）**：
  - **今日小尾巴**：临时中断与短时效闭环，全天静音不弹窗，大块缝隙可主动微注入，下班前「清扫时刻」集中亮起；
  - **别忘 / 已答应**：承诺与模糊责任，**硬编码免疫 14 天自然冷却挥发**，提供 3 分钟 Agent 边界澄清；
  - **随手想法**：半成品想法、连发演化线程与养分，零道德债，超过 **14 天**自动折叠至自然收起区（跨时间/跨入口重复提及或短时连发线程标为「正在发芽」重置冷却）；支持一键投入目标项目的**「待发育口袋」**，待下次切入该 Project L2 或 DSH 专属工作区时自然浮现共同发育，或直接沉淀至 `D-62` 周复盘 `[[复盘/YYYY-Www]]` 反链；
  - **全局水位与近 7 天流转台账（Flow Ledger）**：顶栏以极轻三数呈现当前水位（`小尾巴 N · 别忘 M · 想法 K`），展开浮带可查看近 7 天每条已处理随想的去向并一键直达原文或落点（支持单步改道）。
- **只读不破坏源文件与 macOS TCC Fail Open**：消费、清扫与归档仅写入 Companion 本机索引 `stage-inbox-state.json`（ID + 内容指纹），**绝不删除、移动或回头改写 Logseq / iCloud / Flomo 原始文件**；若遭遇 macOS TCC `EPERM / EACCES`，不崩溃、不阻断画布其余功能，通过 `/stage/inbox-status`、浮带顶部与 `workspace stage-check` 给出可读授权指引。
- **双向 0ms 共振**：悬停或选中条目时，由本地轻量索引 `< 30ms` 即时点亮相关 Area/Project 暖琥珀光与预览弧线（严禁触发云端大模型调用）；平时琥珀光保持收敛，不抢主线注意力。

## 5. 视觉语言、错配优先脉搏与零 emoji 红线

延续 `D-35` 安静工作笔记本风格，**全链路严禁使用 emoji（包括 Unicode 象形箭头）**，禁止虚构健康分、自律打分或完成率百分比。`pulse.ts` 信号优先级如下：

1. **真实错配优先（低饱和暗红，仅用于主线错配）**：宣称 `main` 连续 `>= 7 天` 零推进而其他非搁置领域近 3 天很热闹时，直接点出客观落差；
2. **本季主线定位（克制主色边框）**：突出唯一主线；
3. **近期活跃（清透青绿）**：近 7 天有真实推进；
4. **Inbox 暖琥珀共振**：仅在悬停或显式选中某条 Inbox 时亮灯，平时不分散注意力；
5. **维护模式（低饱和纸灰）**：静默保底，不产生任何变冷或逾期告警。

## 6. 久别重启：类 PPT 极简翻页卡（`D-59`）

针对两类高摩擦回场场景，画布内嵌纯白纸黑字（深色主题对应纯纸暗底）极简翻页重启卡：

- **触发条件**：
  1. **工作台断档 >= 3 天**：基于 `time-stage.json` 记录的 `lastWorkbenchActiveAt`（全新空环境不误触）；
  2. **单个工作/项目 >= 7 天未推进**：进入 L2 时自动提示一次（按 `Esc` 后本次会话不再重复，L2 卡片保留手动「久别重启」按钮）。
- **克制结构与交互**：
  - **最多 3 页，无客观变化自动压缩为 2 页**，每页严格不超过 **3 行主文**；
  - 第 1 页：上次离开时的停点便条、意图与「直达 Logseq 原块」入口；
  - 第 2 页（可自动略过）：离开期间的客观变动（新增相关 iPhone 语音碎片、关联更新、昨日遗留数）；
  - 最后一页：此刻 **10–15 分钟最小启动切口** + 主动作 **`进入现场，开始专注`** + 合法零内疚退路（`旧遗留退回本周` / `不再重要 · 移入搁置` / `转入维护`）；
  - 全键盘操作：`Space` / `ArrowRight` 下一页，`ArrowLeft` 上一页，`Esc` 随时跳过且不关闭底层舞台。

## 7. 人机共编协议与 MCP 原语（`D-54`、`D-56`、`D-57`）

在单工作强边界 `workbench_*`（6 个工具）旁，Companion 并行暴露 **9 个 `stage_*`** 与 **4 个 `time_*`** 原语，并遵循「只读共视 -> 画布虚态 Ghost 提案 -> 用户确认后凝固 + 1 步撤销」三层边界：

| :--- | :--- | :--- | :--- |
| 共视 | `stage_get_view` | 读取当前视野标签、镜头层级、聚焦对象、选中 Inbox 与 `restartDeck` | 只读 |
