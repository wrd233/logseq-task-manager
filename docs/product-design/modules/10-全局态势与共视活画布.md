# 模块需求：全局态势与共视活画布

> 状态：已落地基线（`feat/personal-time-stage-v1`，Sprint 1–3 及实机验收打磨已实现并验证；受[来源与状态](../SOURCE-AND-STATUS.md)及[决策登记](../DECISION-REGISTER.md) `D-50 ~ D-61` 约束）。返回[文档导航](../INDEX.md)。

## 1. 目标与定位

在既有「单工作现场（Logseq 阅读写作 + 单工作强边界协作）」之上，补齐**“抬头看路（Zoom-Out）”的全局态势与时间节奏层**：

- 做完一项具体任务后，可从当前节点平滑拉远镜头，直觉感知长期责任领域（Area）的四态角色（主线 / 支线 / 维护 / 搁置）、近期脉搏与真实错配；
- 在同一悬浮活舞台内完成**三视角切换**（`季节星区 | 本周容器 | 今日容器`），将顶层注意力顺滑落入纯语义有限时间容器（详见 [07-个人规划.md](07-个人规划.md)）；
- 顺手扫视右侧可折叠 **Inbox 浮带**（聚合 iPhone 快捷指令「随口记」iCloud 语音碎片与本地个人 Inbox），悬停 0ms 照亮归属、拖拽安放或批量交由 Agent 梳理；
- 将全局态势与时间容器经由**Agent 无关的本机 Companion MCP** 共享给任意外部 Agent（Antigravity / Codex / Claude Code / DSH），配合 `skills/attention-navigator/SKILL.md` 实现**共视、虚态推演、人拍板凝固**。

核心分工原则（`D-50`）：**人做导演，Agent 做参谋与舞美**——人在画布上只保留极简高频动作（切换视野、点击变焦、选中指代、轻拖定方位或安放 Inbox、拍板留删）；冷启动建模、错配诊断、语音分流与周期装盒由 Agent 承担。

## 2. 载体形态与三视角顶栏

悬浮活舞台支持三种宿主持久接入，同源驱动于 `@task-copilot/stage-runtime` 与本机 Companion SSE（`/stage/events`）：

1. **Logseq 锚定浮层**：从 Logseq 当前工作顶栏「拉远」呼出；点击「开始专注」后浮层退场，仅在 Logseq 顶栏保留一行安静的正向专注计时胶囊（`已进行 Nm`）。
2. **DSH 独立悬浮窗**：支持静默边缘胶囊（Peek）/ 可拖拽缩放悬浮窗 / 全景鸟瞰三态切换（`Cmd/Ctrl+Shift+G`）；在顶栏按钮、浮窗标题栏与边缘胶囊上实时显式标注 `Agent 共视中 · 当前层次与对象`（如 `L0 季节星区` / `L1 运维能力` / `L2 项目-海丝` / `今日容器`），收为胶囊时仍保持与 DSH Agent 的实时共视并在每轮对话 `system-prompt/assemble` 前自动拉取最新视口（含精确层次、`areaId`、`projectWorkKey` 与目录），仅点击关闭（`✕`）后彻底卸载零上下文开销。
3. **独立浏览器窗（`/stage/app`）**：由 Companion 同源托管，可并排摆放在 Codex 终端或 Antigravity 旁实时共视。

顶栏保持克制，仅提供：
- 三视角切换：**`季节星区 | 本周容器 | 今日容器`**；
- **`在 DSH 讨论当前画面`**（Logseq 内无论处于 `L0 / L1 / L2 / L3 / 本周 / 今日` 哪一层，均经由 Companion `/plugin/stage/open-dsh` 直接拉起前台浏览器并携带 `#stage-discuss=1` 自动展开 DSH 悬浮星图进入实时共视，零复制粘贴、不依赖单工作绑定；DSH 内直接引用进当前对话输入框；Antigravity / 外部 MCP 宿主通过 `stage_get_view` 同源共视）；
- 右侧折叠计数按钮 **`Inbox · N`**（不闪烁催办）。

### 2.1 星图与事务专属工作目录的一体化直跳（`D-60`）

承接既有单工作「一事务一文件夹 + DSH 直接以该目录为工作区」的思想，星图各层不再制造割裂的复制粘贴：
- **Area 级（L1 顶卡）**：若对应 Logseq 存在显式 `Area` 页（如 `Area/运维能力`），可直接点「**在 DSH 打开此领域**」或「**领域原文**」，自动准备/复用领域工作目录并跳入 DSH；
- **Project 级（L1 卡片 / L2 主干 / L3 入口）**：直接提供「**在 DSH 打开**」（通过 `ensureDshWork` 准备或复用该 Project 的专属文件夹并建立只读授权、直切 DSH 对应 Session）与「**Logseq 原文**」；
- **嵌套子对象级（L2 原生子对象分支）**：每条原生嵌套子事务/MiniProject 同样提供内联「**在 DSH 打开**」与「**原文**」，方便直接把 Agent 工作区缩小到单个子任务文件夹。

## 3. 四态星区、工作/生活边界与四档语义变焦

### 3.1 季节星区四态模型（`D-56`）

每个顶层 Area（硬控 **4–7 个**）维护轻量四态角色 `focusRole` 与轻度领域边界 `domain`：

| 字段 | 可选值 | 规则与视觉表达 |
| :--- | :--- | :--- |
| `focusRole` | `main`（本季主线） | 严控 1 个，居中微光；记录 1 句 `quarterGoal` 与 1 句 `antiGoal` |
| `focusRole` | `side`（支线） | 常规 2–3 个，承接阶段性并行工作 |
| `focusRole` | `maintenance`（维护模式） | 记录每周最低底线 `weeklyMinimum`，静默保底，**永不报变冷或焦虑提醒** |
| `focusRole` | `parked`（主动搁置） | 移入底部边缘休眠区，随时可一键唤醒 |
| `domain` | `work` / `life` | 工作与个人成长为主线；生活领域一并纳入，以低饱和左边界与极简标签轻度区分 |

### 3.2 四档语义变焦、原生嵌套与多父级归属（`D-60`）

| 镜头层级 | 屏幕主要呈现 | 刻意隐藏 / 弱化 | 核心动作 |
| :--- | :--- | :--- | :--- |
| **L0 季节星区** | 活跃 **Areas** 领地（防重叠双列网格、动态画布高度，带四态标签、脉搏、错配提示与前 3 项核心 Project）；底部文档流「搁置 / 休眠 / 暂放未归类」栏与一键「整理排布」 | 超过 7 个的其余显式 Area、长期静默支线与主动搁置 Area 退入底部休眠栏（可随时一键唤醒）；已归档页面与底层零碎 TODO 隐藏 | 任务收尾后抬头看路；拖动「⋮⋮」固定老家坐标；悬停 Inbox 照亮归属；点击推近 |
| **L1 领域切面** | 当前 Area 英雄卡（含四态角色、工作/生活切换、领域级「在 DSH 打开」）、主归属 **Projects** 卡片（语义清洗后的 1–2 行摘要 + 次归属标签 + 快捷「在 DSH 打开」）、底部的「**跨领域关联**」只读轻分区、领域轻量推进项 | Project 页内的子块收束进 L2，不在 L1 刷屏；无关领域缩成顶部极简邻域按钮；右侧 Inbox 自动上浮本领域共振条目 | 观察领域推进与停滞；通过跨区投影发现多领域协同；直跳 DSH 或就近收编 Inbox |
| **L2 事务结构** | 当前 Project 主干卡（含目录状态、次归属跳转、「在 DSH 打开」「Logseq 原文」「久别重启」）+ 右侧双段分支树：**原生嵌套子对象**（默认展示前 6 项，其余折叠，每条支持直跳 DSH / 原文）+ **轻量推进项与 Agent 虚态推演** | 其他项目收束在顶栏路径中；原始 Logseq 大纲路径与 Markdown 模板词经清洗不直接裸露 | **人机共编黄金层**：查看原生嵌套、直跳子对象目录、观看 Agent 生长虚态分支并拍板留删 |
| **L3 执行入口** | 单项推进说明 + 显式出口：「在 DSH 打开」/「回到 Logseq 原文现场」/「写入 Logseq TODO」/「标记完成」 | 不在悬浮画布内重造大纲编辑器 | 选定下一步后无缝回到 Logseq 或 DSH 专属工作区 |

### 3.3 显式 PARA 领域优先、唯一主归属与小字语义清洗（`D-60`）

- **显式 Area 优先与归档过滤**：`catalog-local.ts` 与 `CatalogWork`（可选 `parentAreas`、`lifecycleState`）原生识别 Logseq 中的 `PARA:: [[PARA/Area]]`、`PARA:: [[PARA/Project]]` 与 `Areas:: [[Area/...]]`，自动过滤 `PARA/Archive` 及 `archived / done / completed / cancelled` 页面与内部块；冷启动检测到显式 Area 时优先按真实 Area 建构 L0（生活类领域自动归为 `domain: "life", focusRole: "maintenance"`），散落条目仅按领域与活跃项目的区分主题词保守匹配，杜绝因图谱名或「整理 / 平台 / 调研」等泛词错误粘连。
- **唯一主归属 + 跨领域投影（多上级处理）**：当一个工作对象同时标注多个上级 Area（如 `Areas:: [[Area/运维能力]] [[Area/AI 自动化能力]]`）时，取首位作为**唯一主归属（Primary Ownership）**，统计数、活跃脉搏与主线错配判定仅计入主归属名下（绝不重复计数）；其余上级作为**次归属关联**，在主归属卡片上显示可点击的 `另关联：xxx` 标签，并在次归属 L1 的「跨领域关联」虚线分区中呈现只读引用卡，点击进入**同一 Project L2、同一工作目录与同一 DSH Session**。
- **卡片小字语义清洗**：通过 `formatWorkSubtitle` 剥离图谱名、`Daily Note` / 时段标题、`**[旧项目内容]**` / `**[资源列表]**:<...>` / `**[推进结构]**` 等容器模板与 Markdown 标记；Project 页展示 `状态 · 含 N 项子事务 · 已绑定目录`，子事务与日记项仅保留最末 1–2 个有效语义位置并做两行截断。

## 4. iCloud 语音入池与 Inbox 双向共振浮带（`D-52`、`D-55`）

- **零摩擦手机语音捕获**：Companion 监听并增量扫描 macOS iCloud Drive 目录 `~/Library/Mobile Documents/com~apple~CloudDocs/TaskCopilotInbox/*.md`（支持环境变量与参数覆盖），解析 `yyyyMMdd-HHmmss.md` 时间戳，标注来源为 `ios-shortcut` / `flomo`，并自动去重 iCloud 冲突副本。
- **只读不破坏源文件**：消费与归档仅写入 Companion 本机索引 `stage-inbox-state.json`（ID + 内容指纹），**绝不删除或移动用户原始 `.md` 备份**。
- **macOS TCC Fail Open**：若遭遇 `EPERM / EACCES`，不崩溃、不阻断画布其余功能，通过 `/stage/inbox-status`、Inbox 浮带顶部与 `workspace stage-check` 给出可读的「系统设置 -> 隐私与安全性 -> 文件与文件夹」授权指引。
- **双向 0ms 共振与 14 天冷却**：
  - 悬停或选中 Inbox 条目时，由本地轻量索引 `< 30ms` 即时点亮相关 Area/Project 暖琥珀光与预览弧线（严禁触发云端大模型调用）；平时 Inbox 琥珀光保持收敛，不抢主线注意力；
  - 支持将 Inbox 直接拖入 Area、Project、本周容器或今日三槽；
  - 超过 **14 天**未触碰的碎片自动折叠至浮带底部「已冷却」区，支持一键批量归档。

## 5. 视觉语言、错配优先脉搏与零 emoji 红线

延续 `D-35` 安静工作笔记本风格，**全链路严禁使用 emoji（包括 Unicode 象形箭头）**，禁止虚构健康分、自律打分或完成率百分比。`pulse.ts` 信号优先级如下：

1. **真实错配优先（低饱和暗红，仅用于主线错配）**：宣称 `main` 连续 `>= 7 天` 零推进而其他非搁置领域近 3 天很热闹时，直接点出客观落差；
2. **本季主线定位（克制主色边框）**：突出唯一主线；
3. **近期活跃（清透青绿）**：近 7 天有真实推进；
4. **Inbox 暖琥珀共振**：仅在悬停或显式选中某条 Inbox 时亮灯，平时不分散注意力；
5. **维护模式（低饱和纸灰）**：静默保底，不产生任何变冷或逾期告警。

## 6. 久别重启：类 PPT 极简翻页卡（`D-59`）

针对两类高摩擦回场场景，画布内嵌纯白纸黑字（深色主题对应纯纸暗底）极简翻页重启卡：

- **触发条件**：
  1. **工作台断档 >= 3 天**：基于 `time-stage.json` 记录的 `lastWorkbenchActiveAt`（全新空环境不误触）；
  2. **单个工作/项目 >= 7 天未推进**：进入 L2 时自动提示一次（按 `Esc` 后本次会话不再重复，L2 卡片保留手动「久别重启」按钮）。
- **克制结构与交互**：
  - **最多 3 页，无客观变化自动压缩为 2 页**，每页严格不超过 **3 行主文**；
  - 第 1 页：上次离开时的停点便条、意图与「直达 Logseq 原块」入口；
  - 第 2 页（可自动略过）：离开期间的客观变动（新增相关 iPhone 语音碎片、关联更新、昨日遗留数）；
  - 最后一页：此刻 **10–15 分钟最小启动切口** + 主动作 **`进入现场，开始专注`** + 合法零内疚退路（`旧遗留退回本周` / `不再重要 · 移入搁置` / `转入维护`）；
  - 全键盘操作：`Space` / `ArrowRight` 下一页，`ArrowLeft` 上一页，`Esc` 随时跳过且不关闭底层舞台。

## 7. 人机共编协议与 MCP 原语（`D-54`、`D-56`、`D-57`）

在单工作强边界 `workbench_*`（6 个工具）旁，Companion 并行暴露 **9 个 `stage_*`** 与 **4 个 `time_*`** 原语，并遵循「只读共视 -> 画布虚态 Ghost 提案 -> 用户确认后凝固 + 1 步撤销」三层边界：

| 分层 | 原语名称 | 语义说明 | 影响范围 |
| :--- | :--- | :--- | :--- |
| 共视 | `stage_get_view` | 读取当前视野标签、镜头层级、聚焦对象、选中 Inbox 与 `restartDeck` | 只读 |
| 共视 | `stage_get_pulse` | 拉取四态星区、错配信号、iCloud 诊断、Inbox 列表与 `restartDeck` | 只读 |
| 提示 | `stage_highlight` | 点亮视野内目标；视野外目标降级为边缘方向雷达（不抢镜头） | 瞬态 UI |
| 提示 | `stage_annotate` | 在节点旁附加简短见解便签 | 瞬态 / 轻量标注 |
| 推演 | `stage_propose_areas` | 冷启动生成 4–7 个四态领域虚态星图（先口述全景再对照补全） | 虚态缓冲 |
| 推演 | `stage_propose_area_role` | 提议调整四态角色、工作/生活归类、季度目标/反目标/周底线（含单主线置换） | 虚态缓冲 |
| 推演 | `stage_sprout_branches` | 在父节点下错峰生长虚态推进分支 | 虚态缓冲 |
| 推演 | `stage_propose_move` | 预览工作或 Inbox 归属迁移 | 虚态缓冲 |
| 落盘 | `stage_resolve_proposals` | 经用户拍板凝固或散去虚态提案，带 1 步 Undo | 方案 A 运营态 |
| 时间 | `time_get_overview` | 读取本周容量、今日三槽、Apple 日历硬日程、遗留项、专注态与断档天数 | 只读 |
| 时间 | `time_propose_plan` | 虚态提议本周推进块、今日排期、遗留分流或突发救火收窄 | 虚态缓冲 |
| 时间 | `time_resolve_proposals` | 经用户确认后凝固或散去时间虚态提案，带 1 步 Undo | 时间运营态 |
| 时间 | `time_focus_control` | 启动/暂停/恢复/结束专注（留停点便条、可选写足迹）或单键创建上午日历护盾 | 执行态 / 日历 |

外部 Agent 配套人格与四剧本（季度冷启动、周日复盘、突发救火、断档重启）定义在 `skills/attention-navigator/SKILL.md`。

## 8. 最小数据边界与未决项

- **不膨胀 Formal Kernel**：`apps/kernel-service` 保持完全独立冻结；`stage-areas.json`、`stage-inbox-state.json`、`time-stage.json` 均为 Companion 轻量运营层。
- **仍保留的后续演进边界**：
  1. 多 Agent 同时连接同一 Companion 时的虚态分组分色与并发写冲突策略；
  2. 独立原生 macOS 置顶轻壳（当前由 `/stage/app` + Logseq 浮层 + DSH 悬浮窗覆盖）；
  3. 跨宿主（外部终端 vs Logseq 可信渠道）升级写入正式 Kernel 任务的统一授权路径（与未决边界 #4 联动）。
