# 模块需求：个人规划与纯语义时间容器

> 状态：已落地基线（`feat/personal-time-stage-v1`，Sprint 2–3 已上收至中立 Companion 并验证；受[来源与状态](../SOURCE-AND-STATUS.md)及[决策登记](../DECISION-REGISTER.md) `D-57 ~ D-59` 约束）。返回[文档导航](../INDEX.md)。

## 1. 目标与边界

帮助用户把真正重要的推进事项落进**有限、真实、低焦虑的纯语义时间容器**，而不是维护僵硬的精确工时表：

- **上收中立 Companion**：语义时间引擎（`@task-copilot/stage-runtime` 的 `time-model.ts` / `time-engine.ts`）与持久化（`time-stage.json`）运行在本机 Companion，不再绑定 DSH 存活；Logseq、DSH、独立窗 `/stage/app` 与任意 MCP Agent 共享同一份实时状态。
- **不膨胀 Formal Kernel**：时间容器只记录用户的投入意向、真实专注累计与停点便条，不修改 `apps/kernel-service` schema，也不替代正式任务或篡改 Logseq 原文。
- **纯语义为主，精确钟点为例外**：绝不绘制 `08:00–22:00` 密格时间轴；只有具备明确起止时间的事项（Apple 日历硬日程、或用户主动写入的单个上午主线护盾块）才显示精确起止钟点。

## 2. 四层嵌套纯语义时间容器

1. **季节容器（90 天 · 季节星区）**：承接 `1 主线 + 2–3 支线 + 维护底线 + 搁置`，详见 [10-全局态势与共视活画布.md](10-全局态势与共视活画布.md)。
2. **周容器（7 天 · 本周容器）**：
   - 常规承接本周真正承诺的 **3–5 个推进块（Major Moves）**；
   - 结合 Apple 日历本周硬日程密度自动计算可用空间：当本周硬日程总时长 `>= 12 小时` 或有 `>= 3 天` 硬日程 `>= 2.5 小时` 时，自动标为密集周并将建议容量收窄至 **1–3 块**；
   - 顶部极细一行展示周一至周日固定日程概览，右侧默认提供本季主线/支线待选项一键拉入，也支持从 Inbox 直接拖入。
3. **日语义容器（当天 · 今日容器）**：
   - 按脑力质地划分为三只语义槽：
     - **`上午 · 深潜`**（建议容积 **1 项**，护住当天主线硬骨头）；
     - **`下午 · 推进`**（建议容积 **1–2 项**，中轻度推进、沟通或集中整理）；
     - **`晚上 · 轻放`**（建议容积 **1 项**，阅读或个人事务，**显式允许留白**）。
   - **满载温柔阻力（Gentle Friction）**：向已满槽位放入新项时不报错阻断，而在顶部给出克制选择——**替换当前 / 顺延至明天 / 仍然叠加**。
   - **昨日遗留托盘（防滚雪球）**：未完成项次日绝不自动挤进今日三槽，而是安静停在顶部托盘，提供 **放入今日 / 退回本周 / 撤掉**；系统按日幂等累计 `carryoverCount`，当连续遗留 `>= 3 次` 时自动标出，供用户与 `Attention Navigator` 按「不清晰 / 有抗拒 / 不重要」三因拆解。
4. **此刻微容器（Logseq 安静专注胶囊）**：
   - 从今日容器点击「开始专注」，Companion 经 `macos-focus.ts` 精确前置目标 Logseq 实例并定位对应工作，悬浮活舞台自动退场；
   - Logseq 顶栏仅保留一行安静的**纯正向计时**状态（绝不做倒计时、不放红字警告）：
     `上午 · 主线：xxx · 已进行 28m  [ 暂停 ]  [ 结束 ]  [ 拉远 ]`
   - 结束时可选留 1 句停点便条（`stopNote`），同步回写至日/周推进项与专注记录，并累计本周各领域真实投入分钟数，同时作为下次「久别重启」翻页卡的第 1 页真实依据。

## 3. Apple 日历三层轻协同（`D-58`）

通过 macOS 原生 JXA（`osascript -l JavaScript`，参数经 `argv` 传递防注入）实现渐进式三层协同，全程遵循 **TCC Fail Open**（权限拒绝 `-1743` 或非 macOS 环境时自动退回纯语义槽位并给出可读指引）：

1. **第一层 · 只读硬日程（默认）**：读取具备明确起止时间的非全天固定日程（60 秒缓存），分别叠入本周概览与今日三槽，实时算出各槽位剩余可用时长。
2. **第二层 · 单键写入上午主线护盾**：对「上午·深潜」中的单条主线事项提供一次性「写入日历护盾」按钮（默认 `09:30–11:30`，带 `[主线护盾]` 标记），方便同步至 iPhone 锁屏做温和提醒。
3. **第三层 · 反向日历足迹（默认关闭，用户显式开启）**：开启后，每次结束 `>= 1 分钟` 的专注会话时，将真实起止时段与停点便条静默写入独立子日历 `Task Copilot 足迹`，供周日复盘做“宣称主线 vs 真实投入”客观对照。

## 4. 三大日常节拍与外部 Agent 协同

- **早上开局（<= 2 分钟）**：看一眼今日硬日程 -> 10 秒清理昨日遗留 -> 放 1 件主线进「上午·深潜」 -> 点「开始专注」进入 Logseq（早上不刷 Inbox）。
- **晚上收尾（<= 3 分钟）**：离开电脑前点「结束」留 1 句停点；下班路上用 iPhone 快捷指令「随口记」语音倾倒进 `TaskCopilotInbox`。
- **周日复盘（10–15 分钟）**：由外部 Agent 配合 `skills/attention-navigator/SKILL.md` 调用 `stage_get_pulse` + `time_get_overview`，输出 5 行客观事实镜、批量分流语音 Inbox、点破主线错配、虚态装盒下周推进块（`time_propose_plan` -> 用户拍板 `time_resolve_proposals`）。
- **久别重启与突发救火**：断档 `>= 3 天` 自动触发 2–3 页纯文字翻页重启卡（支持一键「旧遗留退回本周」或「进入现场，开始专注」）；当日日程突崩时经 `time_propose_plan(kind="day-rescue")` 收窄至 1 件现实可完成动作。

## 5. 验收基线

1. 不依赖 DSH 进程即可在 Logseq 浮层、独立窗 `/stage/app` 与 MCP Agent 间实时同步季/周/日与专注状态。
2. 全界面零 emoji、零 `08:00–22:00` 密格时间轴、零健康分/完成率焦虑指标。
3. 密集日历周自动收窄建议容量至 1–3 块；今日满载槽位触发温柔阻力（替换/顺延/叠加）；未完成项次日进入昨日遗留托盘且 `>= 3 次` 触发重复遗留标记。
4. macOS 日历权限未授或非 macOS 环境时 Fail Open 不报错；单键主线护盾与可选足迹子日历均可控。
5. Logseq 专注胶囊纯正向计时，结束可留停点便条并累计真实投入，反哺本周视图与久别重启卡。
6. 所有 Agent 排期均先以虚态呈现，用户确认后落盘并支持单步撤销，绝不静默改写 Logseq 原文或 Formal Kernel。
