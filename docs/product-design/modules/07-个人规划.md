# 模块需求：个人规划与纯语义时间容器

> 状态：已落地基线（`feat/personal-time-stage-v1`，Sprint 2–3 及实机验收打磨已上收至中立 Companion 并验证；受[来源与状态](../SOURCE-AND-STATUS.md)及[决策登记](../DECISION-REGISTER.md) `D-57 ~ D-59, D-61, D-63` 约束，其中 `D-63` 清扫时刻与三口袋协同为已确认待实施契约）。返回[文档导航](../INDEX.md)。

## 1. 目标与边界

帮助用户把真正重要的推进事项落进**有限、真实、低焦虑的纯语义时间容器**，而不是维护僵硬的精确工时表：

- **上收中立 Companion**：语义时间引擎（`@task-copilot/stage-runtime` 的 `time-model.ts` / `time-engine.ts`）与持久化（`time-stage.json`）运行在本机 Companion，不再绑定 DSH 存活；Logseq、DSH、独立窗 `/stage/app` 与任意 MCP Agent 共享同一份实时状态。
- **不膨胀 Formal Kernel**：时间容器只记录用户的投入意向、真实专注累计与停点便条，不修改 `apps/kernel-service` schema，也不替代正式任务或篡改 Logseq 原文。
- **纯语义为主，精确钟点为例外**：绝不绘制 `08:00–22:00` 密格时间轴；只有具备明确起止时间的事项（Apple 日历硬日程、或用户主动写入的单个上午主线护盾块）才显示精确起止钟点。

## 2. 四层嵌套纯语义时间容器

1. **季节容器（90 天 · 季节星区）**：承接 `1 主线 + 2–3 支线 + 维护底线 + 搁置`，详见 [10-全局态势与共视活画布.md](10-全局态势与共视活画布.md)。
2. **周容器（7 天 · 本周容器）**：
   - 常规承接本周真正承诺的 **3–5 个推进块（Major Moves）**；
   - 结合 Apple 日历本周硬日程密度自动计算可用空间：当本周硬日程总时长 `>= 12 小时` 或有 `>= 3 天` 硬日程 `>= 2.5 小时` 时，自动标为密集周并将建议容量收窄至 **1–3 块**；
   - 顶部极细一行展示周一至周日固定日程概览，右侧默认提供本季主线/支线待选项一键拉入，也支持从 Inbox 直接拖入。
3. **日语义容器（当天 · 今日容器）**：
   - 按脑力质地划分为三只语义槽：
     - **`上午 · 深潜`**（建议容积 **1 项**，护住当天主线硬骨头）；
     - **`下午 · 推进`**（建议容积 **1–2 项**，中轻度推进、沟通或集中整理）；
     - **`晚上 · 轻放`**（建议容积 **1 项**，阅读或个人事务，**显式允许留白**）。
   - **满载温柔阻力（Gentle Friction）**：向已满槽位放入新项时不报错阻断，而在顶部给出克制选择——**替换当前 / 顺延至明天 / 仍然叠加**。
   - **昨日遗留托盘（防滚雪球）**：未完成项次日绝不自动挤进今日三槽，而是安静停在顶部托盘，提供 **放入今日 / 退回本周 / 撤掉**；系统按日幂等累计 `carryoverCount`，当连续遗留 `>= 3 次` 时自动标出，供用户与 `Attention Navigator` 按「不清晰 / 有抗拒 / 不重要」三因拆解。
   - **大块间隙微注入与下午「清扫时刻（Sweep Window）」（`D-63`，已确认待实施）**：
     - 针对白天最常见、最消耗工作记忆的「临时中断 / 当时没能完成但应尽快完成的事」，平时严禁弹窗提醒打断深潜，只静默收进**「今日小尾巴」**托盘；
     - 在两个大时间块之间出现 10–20 分钟缝隙时，允许用户**主动拉取（Pull）** 1–2 件小尾巴微注入完成；
     - 每天下午下班前设定一个固定 **15–25 分钟「清扫时刻」**（例如 `17:15`），作为全天唯一主动亮起的泄洪窗口：集中扫光今日小尾巴（超过 15 分钟的重活强制踢出转去澄清或周池，防止堵死清扫节奏），末尾花 2 分钟防漏扫一眼**「别忘 / 已答应」**承诺池（免疫 14 天挥发），随后留停点便条关机下班，彻底释放工作记忆。
4. **此刻微容器（Logseq 安静专注胶囊与静心降噪现场恢复，`D-61`）**：
   - 从今日容器点击「开始专注」，系统**先拍摄进入专注前的完整现场快照**（Logseq 左/右侧边栏开关态、工作台侧栏当前面板、当前所在页面或 Journals），再由 Companion 经 `macos-focus.ts` 精确前置目标 Logseq 实例并定位对应原生页面/块，悬浮活舞台自动退场；
   - 自动收起工作台侧栏与 Logseq 左/右侧边栏，并激活克制的静心降噪态（`body.tc-focus-zen`）：顶部 2px 细线作为专注边界提示，Logseq 顶栏左右工具组与右下帮助按钮低存在感淡化（鼠标悬停即刻恢复清晰，不锁定操作）；
   - Logseq 顶栏仅保留一行显式声明 `-webkit-app-region: no-drag`（避免 macOS 标题栏拖拽拦截）的**纯正向计时**胶囊（绝不做倒计时、不放红字警告）：
     `上午 · 主线：xxx · 已进行 28m  [ 静心 ]  [ 暂停 ]  [ 结束 ]  [ 拉远 ]`
     其中「静心」可随时开关降噪而不中断计时；「暂停」自动抬起顶栏淡化；
   - 结束专注（无论在顶栏胶囊、独立窗、DSH 或 MCP 触发）时，可选留 1 句停点便条（`stopNote`，支持 `Esc` 取消输入）并累计本周真实投入，同时**自动卸除静心样式并无损恢复进入专注前的侧栏、工作台面板与原页面**。

## 3. Apple 日历三层轻协同（`D-58`）

通过 macOS 原生 JXA（`osascript -l JavaScript`，参数经 `argv` 传递防注入）实现渐进式三层协同，全程遵循 **TCC Fail Open**（权限拒绝 `-1743` 或非 macOS 环境时自动退回纯语义槽位并给出可读指引）：

1. **第一层 · 只读硬日程（默认）**：读取具备明确起止时间的非全天固定日程（60 秒缓存），分别叠入本周概览与今日三槽，实时算出各槽位剩余可用时长。
2. **第二层 · 单键写入上午主线护盾**：对「上午·深潜」中的单条主线事项提供一次性「写入日历护盾」按钮（默认 `09:30–11:30`，带 `[主线护盾]` 标记），方便同步至 iPhone 锁屏做温和提醒。
3. **第三层 · 反向日历足迹（默认关闭，用户显式开启）**：开启后，每次结束 `>= 1 分钟` 的专注会话时，将真实起止时段与停点便条静默写入独立子日历 `Task Copilot 足迹`，供周日复盘做“宣称主线 vs 真实投入”客观对照。

## 4. 四大日常节拍与外部 Agent 协同

- **早上开局（<= 2 分钟）**：看一眼今日硬日程 -> 10 秒清理昨日遗留 -> 放 1 件主线进「上午·深潜」 -> 点「开始专注」进入 Logseq（早上不刷任何随想与杂事）。
- **白天大块间隙（按需拉取，绝不主动弹窗）**：突发中断或闪念 3 秒卸进对应入口释放脑内存；整块工作缝隙可主动从「今日小尾巴」捞 1–2 件小事微注入。
- **下午下班前「清扫时刻」与收尾（15–25 分钟，`D-63`）**：固定下班前打开「今日小尾巴」一口气清光当天短时效闭环（重活踢出转澄清/周池），末尾 2 分钟核对「别忘 / 已答应」防掉链子，在 Logseq 顶栏点「结束」留 1 句停点便条安心下班；下班路上用 iPhone「随口记」语音卸压。
- **周日复盘（10–15 分钟）**：由外部 Agent 配合 `skills/attention-navigator/SKILL.md` 与 `D-62` 全局导航台调用 `stage_get_pulse` + `time_get_overview`，输出 5 行客观事实镜、复核所有活跃「别忘 / 已答应」承诺、按三叠牌批量分流「随手想法」（含语音拆条、项目待发育投递、Flomo 共鸣、周复盘 `[[复盘/YYYY-Www]]` 反链沉淀与 14 天自然挥发）、点破主线错配、虚态装盒下周推进块（`time_propose_plan` -> 用户拍板 `time_resolve_proposals`）。
- **久别重启与突发救火**：断档 `>= 3 天` 自动触发 2–3 页纯文字翻页重启卡（支持一键「旧遗留退回本周」或「进入现场，开始专注」）；当日日程突崩时经 `time_propose_plan(kind="day-rescue")` 收窄至 1 件现实可完成动作。

## 5. 验收基线

1. 不依赖 DSH 进程即可在 Logseq 浮层、独立窗 `/stage/app` 与 MCP Agent 间实时同步季/周/日与专注状态。
2. 全界面零 emoji、零 `08:00–22:00` 密格时间轴、零健康分/完成率焦虑指标。
3. 密集日历周自动收窄建议容量至 1–3 块；今日满载槽位触发温柔阻力（替换/顺延/叠加）；未完成项次日进入昨日遗留托盘且 `>= 3 次` 触发重复遗留标记。
4. macOS 日历权限未授或非 macOS 环境时 Fail Open 不报错；单键主线护盾与可选足迹子日历均可控。
5. Logseq 专注胶囊在 macOS 标题栏区域完全可点击，纯正向计时，支持「静心」降噪切换；结束可留停点便条、累计真实投入并自动恢复专注前现场（侧栏、工作台面板与原页面）。
6. 所有 Agent 排期均先以虚态呈现，用户确认后落盘并支持单步撤销，绝不静默改写 Logseq 原文或 Formal Kernel。
