## 1. 定位与边界

本设计回答一个先于具体模块的问题：**作为一套天天贴身使用的私人工作与思考系统，人从早到晚究竟如何毫无负担地穿过它，以及它在屏幕上应当呈现怎样的统一气质。**

它不是推翻现有的四层时间容器（`D-57`）、悬浮活舞台（`D-51`）、全局导航台（`D-62`）和随想三口袋（`D-63`），而是从「人一整天的真实节律」出发，将分散的模块与新增能力收拢进同一套极简哲学与视觉语法中。

### 明确的数据与载体边界（本阶段）
- **载体分工**：工作日以 Mac 桌面（Logseq + 本机 Companion + DSH）为主战场；手机端仅承担离开电脑或周末时的轻查看与语音兜底，不做重型多层级拖拽看板。
- **今日拼图三大核心源**：聚焦 **Logseq（含每日 Journal）+ iPhone 随口记 + 本工作台记录（专注/停点/工单/随记）**，先跑顺内循环，暂不外接 Flomo、Day One、Apple 备忘录等第三方笔记软件。
- **明确暂缓项**：WPS / Excel 等外部重软件的主窗口接管与桌面分屏排版明确不硬塞进狭小的 Logseq 插件界面，留待后续更合适的独立宿主形态另行设计。

## 2. 简单的产品哲学（四条第一性原理）

全站所有交互、排版、文案与动效，均由以下四条原则直接推导；任何新功能若违背其中一条，应当削减而非叠加解释。

### 原则一：按人的心理节律分场，不按软件结构分栏
人一天只有四种心理状态：**定调（极速拍板）/ 潜入（低头推进）/ 换气（接住碎片与中断）/ 回望（抽离觉察与复利）**。界面不按“任务模块、笔记模块、AI 模块”切分，而只随心理状态切换——绝不逼人在上午清脑时发散规划，绝不在干活中途弹出情绪追问，绝不在下班累瘫时强迫写长复盘。

### 原则二：纸面为主，助手在侧
延续 `D-35 / D-61` 的安静工作笔记本美学。白天 80% 的时间，屏幕主体永远是一张干净的纸（Logseq 原生编辑面）；系统提供的所有增强能力（随记区、工单小抄、恢复卡、榨干草稿、旧念头共振）都只表现为贴在纸边的**细线、便签条或可收起折页**，绝不做成高对比后台看板或重型弹框。

### 原则三：人做导演，AI 扛「冷启动税」与「收尾税」
AI 不替用户做决定、不静默改写 Logseq 原文、也不扮演温情心理咨询师。AI 只集中承接人脑最抗拒的四项高摩擦苦力：
1. **探路**：工单/杂活后台查历史笔记吐 3 行小抄；
2. **垫底**：随记整理预览卡、急事后台草拟停点、完成时预拟 3–5 行文档/SOP 草稿；
3. **递镜子**：久别重逢的 3 段恢复卡、晚间 5 行客观事实镜与反差切口；
4. **递旧念头**：现场共振提示与低频限流抽卡。

人只保留最高价值、最低耗能的动作：**花 5–10 秒改两个字、点拍板，或坦然跳过**。

### 原则四：先轻后重，诚实留白
所有事物默认以最轻形态进入（小事默认进今日工作区、心情默认一句话进反思流、想法默认零道德债挂靠领域）；只有经现实证明足够重要或重复出现时，才自然升格（升格独立工作区、第 2 次出现提示存 SOP、共振发酵成文章/项目）。一切复盘、榨干与深聊都内置合法的跳过与延期出口——**零红点、零倒计时、零打卡债、零虚假评分、零 emoji**。

## 3. 符合使用心智的四态空间模型

用户不需要记住十几个零碎功能，只需在心智里记住**一天只穿过四个边界清晰的空间**：

```text
  [ 前晚 5 分钟 / 早晨 2 分钟 ]          [ 白天 80% 时间 ]
       1. 桌面总览（抬头看路）   ------->    2. 纸面现场（低头干活）
          · 左：硬日程 + 语义槽                 · 今日默认工作区（锚定 Journal）
          · 右：晚间澄清 / 早间拍板             · 独立事务工作区（按需升格）
                 ^                                    |  ^
                 | 傍晚务实收口                        |  | 0-10 秒轻进轻出
                 |                                    v  |
       4. 安静回望室（晚间按需）  <-------   3. 微缝中转站（极速换气）
          · 5 行自动今日快照                    · 丢入：工单暂存 / 午间一句反思
          · 事实镜 + 直击反差深聊               · 撤离：急事双速停点条
          · 尾声 1-2 张旧想法抽卡               · 轻审：随记 5 秒卡 / 收尾榨干卡
```

## 4. 全天真实动线与规则细化

### 4.1 错峰定调：日程模块「本周 | 今日 | 明日」三态接力（`D-64`）
早间拍板与前晚构思不是独立于日程之外的另一套东西，而是现有日程模块（`@task-copilot/stage-runtime` + Companion `TimeHub`）共享同一份数据在不同时间点的视图：
- **本周视角**：承接本周 3–5 个推进块（`weekMoves`）与 7 日 Apple 日历会议密度，支持一键把推进块排入今日或明日；
- **明日视角（前晚构思态 · 离开电脑前 5 分钟）**：面对明天（`T+1`）的三语义槽与明日硬日程，在右侧展开模糊承诺原话与上层项目方向，澄清并预装明天能干的具体动作；
- **今日视角（早间拍板态 · 次日早上 <= 2 分钟）**：昨晚排好的「明日」自动成为「今日」；右侧收起模糊承诺与宏大项目，只留已明确待办与昨日遗留，2 分钟微调后直接进入对应的 Logseq Page 或 Block 现场。

### 4.2 回归原生 Logseq 笔记体系：Page / Block 双粒度共生，取消 Logseq 内自动收尾（`D-65`）
纸面现场绝不脱离普通笔记体验，核心本体就是正统的 Logseq 块大纲编辑器（支持普通页面、今日 Journal、独立 Page 事务及**只在块中的 Block 级事务**）：
- **Page 与 Block 双粒度无缝切换**：复用底层已支持的 `WorkRef(sourceKind: 'block' | 'page')`；进入块级事务时直接调用 Logseq 原生 **Block Zoom-in**（顶部带原生面包屑可一键退回父页），画面只剩该块与子块，退回父页时保持干净折叠；
- **普通笔记零打扰**：切入普通读书笔记或随笔页时，工作态顶栏自动隐退，100% 保持原生纯净记录；
- **所有增强长在原生块里**：
  - **停点块**：暂停写入的停点是顶部可点击的原生块，点击或从日程/恢复页进入时，光标平滑定位并柔光微亮上次停笔行；
  - **「自由随记」原生块（双形态同源）**：页内/块下的普通 `自由随记` 父块及其子块，块头悬停仅留 `标给 Agent` 与 `悬浮`；按 `Ctrl+.` 盲写的闪念直接作为新子块追加其下；
- **Logseq 内取消「自动收尾」，收尾交由与 Agent 对话完成**：不在 Logseq 笔记现场放「收尾」按钮，也绝不自动往正文里硬塞整理块或页首大汇报横幅；事务收尾、对外一句话提炼与 SOP 沉淀改由右侧工作台进入 DSH / Agent 对话，由用户参与共同完成。

### 4.3 突发中断双通道：工单后台预消化与急事双速撤离（`D-65`、`D-66`）
白天面对两类完全不同紧迫度的打断，走两条独立通路：
- **通道 A · 非致命杂活 / 工单（异步预消化 + 45 分钟间隙秒清）**：
  - 工单到来但不想打断主线时，通过复制或截图一键丢入后台暂存区；
  - Agent 在后台**优先检索历史笔记与过往同类 SOP**，命中后压成一张**不超过 3 行的极简小抄**（去哪做 / 填什么 / 有哪些坑）；
  - 遇到从未见过的新工单时**严禁编造内部流程**，仅诚实提炼对方核心诉求与需要确认的 1–2 个缺口；
  - 等 45 分钟专注自然告一段落，点开小抄极速秒掉；新工单做完后顺手走收尾榨干，沉淀为下次的 3 行小抄，形成自增长飞轮。
- **通道 B · 迫不及待的紧急中断（双速撤离，绝不卡人）**：
  - 点击暂停瞬间立刻弹出极简单行输入框，绝不等待 AI 生成：
    - **快手档**：有 3 秒余力，顺手敲十几个字（做到哪 + 下一步）回车即切走；
    - **零阻档**：火烧眉毛来不及写，直接点**「先走」**立刻释放焦点；Agent 趁用户处理急事在后台结合刚才动过的随记与文件变动草拟一句停点，待用户回来或稍后空闲时补确认与微调。

### 4.4 自适应冷启动恢复（`D-65`）
根据离开该事务的时间长短，自动匹配恢复深度，避免短时切回的弹窗骚扰与长期未碰的失忆感：
- **短时切回（当天或隔天）**：不弹窗、不遮罩；仅在工作区顶部细线上安静显示 **1 行「上次落脚点」**（优先显示用户中断时亲手写/改的那一句）。
- **久别重逢（超过 3–7 天未碰）**：进场时展开**三段式极简恢复卡**（延续 `D-59` 纯纸翻页或三段式卡片，空格翻页 / Esc 跳过）；每页仅对 **2–3 个核心关键词** 做加粗与克制着色（雾蓝标目标/直达入口，暖琥珀标唯一卡点），绝不整段花哨标注：
  1. **总体核心概括**：这件事原本想达成什么核心意图；
  2. **最近关键想法与选型**：期间做过的决定、最新进度与客观变化；
  3. **上次具体落脚点**：明确标出你上次离开时亲手留下的那句话，附主按钮「进入现场」与合法退路「移入搁置/维护」。

### 4.5 分级收尾「榨干产出」（`D-66`）
解决“想沉淀复利，但干完活累到懒得写文档”的矛盾：
- **独立事务 / 首次遇到的新工单**：点击「完成」时，Agent 先基于过程随记与变更自动预拟 **3–5 行极简草稿**（大项目归档清单 / Bug 排障坑点 / 4 步日常 SOP），用户只需 10 秒四选一：
  `确认归档` / `改两字保存` / `一次性琐事，跳过` / `先完成，延到今晚`
- **今日默认工作区的普通琐事**：默认**静默完成、零弹窗打扰**；仅当系统识别同类小事重复出现第 2 次时，温和提示一句「这件事已处理过两次，是否存成 3 行小抄？」。

### 4.6 午间独立反思流与晚间纯自我手记（`D-67`）
彻底隔离“白天干活的理性场”与“面对自我的安静手记场”，**只留下我自己的想法，绝不让 Agent 喧宾夺主引入大量 AI 观点**：
- **午间 / 安静时刻 · 零摩擦快记感受**：
  - 复用 iPhone「随口记」或电脑全局快记，随口记下一句当时的感受或反应，自动归入晚间参考流，绝不混入任务池、绝不当场追问。
- **晚间安静回望室 · 你的空白手记页**：
  - **不做「AI 聊一聊」、不做选择题、不灌输 AI 观点**；
  - 左侧以极淡纯文字安静列出今天客观发生过的脚印（专注记录、随口记原话、工单、日记新增），纯粹用于帮自己想起今天发生了什么，点击可查原记录；
  - 右侧绝对主角是一整片无边框空白手记纸面，用来直接写下**我自己的想法与反思**（不写也完全合法，今日脚印已自动留档）；
  - Agent 默认完全闭嘴；仅当用户自己卡壳、主动点「写不出来时，给 1 句简单提问」时，才在底行轻给一句大白话短问，绝不替用户下结论、绝不把 AI 文字写入用户日记。

### 4.7 想法的「分阶段持续补充」生长机制（`D-67`）
不把零散想法做成白天侧栏的审批推送，也不急着交给 AI 改写或强行拆成事务：
- 每条想法以**无框按日期叠加的生长时间线**保存（如 11-11 刚想到 -> 11-18 补充 -> 今天再补两句）；
- 在晚间手记页下方顺手补写新体会，让想法随时间自然长厚，不设催办与任务转化压迫。

## 5. 统一产品表现系统：无盒纸面与心流隐身（`D-68`）

吸取 **Things 3（留白与排版代替框线）**、**iA Writer（打字即隐身框架与逐段聚焦）** 与 **Linear（低饱和单点强调）** 三条成熟哲学，彻底消除“格式大于内容、注意力被边框和按钮切碎”的问题。

### 5.1 治好“格式大于内容”与柔和注意力引导的五条硬规则

1. **无盒纸面（Zero-Box Paper）**：全站统一一张连贯的宣纸/暗纸底色，**彻底消灭「卡片里套卡片」与多余圆角框**；分组只靠大留白（32–44px）、字重差与极淡的 1px 细线撑开；去掉 85% 的装饰性图标，让眼睛第一眼只看见内容本身。
2. **主次视线分流与柔光联动**：
   - 桌面总览右侧候选项默认退后一步降低对比；悬停「上/下/晚」时，左侧对应语义槽轻柔亮起 2px 静蓝边线呼应，放入后新项呼吸高亮一次后归于平静，眼睛无需满屏寻找落点；
   - 晚间手记左侧今日脚印默认淡化；点击某条脚印「顺着写」时，该条清晰高亮作伴、其余脚印淡退，光标直接落入右侧纯白手记区。
3. **精准回锚 + 600ms 丝滑心流隐身**：
   - 从桌面总览、冷启动第 3 页、页首停点块或「抬头换气」清完小抄返回笔记时，光标自动平滑滚回**上次停笔的那一行**并柔光呼吸一次，零迷路；
   - 开始敲字约 1 秒后，顶栏、左侧目录与外围控制以 `600ms` 丝滑淡出，同时开启逐段台灯聚焦（非当前编辑块柔和淡化）；专注期间彻底隐藏工单小抄与跳动计时，只在主动点「抬头换气」时温柔浮现。
4. **不离眼盲写卸闪念**：心流中途按 `Ctrl+.` 在视野中央浮出无框单行输入，回车立刻消失并作为子块写入本页 `自由随记` 原生块，眼睛 2 秒回到原句。
5. **界面自明，零说教文案**：严禁在界面中写解释产品理念的副标题或宣传语，用容量微点、2px 实线/1px 虚线来源区分与可撤销回执直接传递安心感；全链路坚守零 emoji、零红点、零倒计时。

### 5.2 仅用 4 种 UI 原语覆盖全天所有场景

| UI 原语 | 形态隐喻与位置 | 视觉特征 | 统一承载的场景（绝不另造异形弹窗） |
| :--- | :--- | :--- | :--- |
| **1. 顶栏状态细线**<br>`Quiet Ribbon` | 贴在纸面最顶端的 2px 边界与单行铅笔眉注 | 低对比单行纯文本，无阴影盒、无彩色大徽章，打字自动淡出、悬停即现 | 专注状态、短时切回的「1 行上次落脚点」、暂停/收尾/工作台入口；计时与工单小抄专注时隐藏，仅在「抬头换气」时浮现 |
| **2. 纸条微确认卡**<br>`10-Second Slip` | 贴于纸页边缘或光标旁的素色轻条，用完即走 | 极简三段结构：**短标题 + 3 行纯文 + 极少文字动作**；全键盘支持（`Enter` / `Esc`） | 急事双速暂停条；工单 3 行小抄；午间一句感受快记；`Ctrl+.` 盲写卸闪念 |
| **3. 静默侧边折页**<br>`Quiet Margin` | 贴于主纸面右侧的 1px 淡线纸栏，平时完全收起 | 零厚重阴影卡片，复用 Logseq 渐进工作台 | 复用 `文章`（点短语展开）与 `材料`、以及 `在 DSH 继续协作` |
| **4. 纯纸幕布**<br>`Clean Sheet` | 切入另一个心理频道时的全幅留白无盒纸页 | 高留白、大行距、去卡片边框，靠留白与字重分层 | 桌面总览（前晚构思 / 早间拍板）；>3–7 天久别重逢的 3 段式恢复页；晚间纯自我手记页 |

### 5.3 一眼可辨的「人机来源区分语法」
在整个系统里，用户最怕 AI 的总结不知不觉覆盖或冒充自己的真实记忆。因此，凡是用户原话与 Agent 提炼同屏出现处（恢复页、停点草稿、小抄来源），强制采用统一的排版编码：
- **用户亲口/亲手原话**（中断停点、模糊承诺原话、随口记感受）：正常深墨色正文 + 左侧 **2px 实线竖杠**，代表“这是你本人说过的话，权威最高”。
- **Agent 观察 / 提炼 / 建议**（小抄步骤、摘要、后台补写停点）：略浅一级中性灰 + 左侧 **1px 虚线竖杠**及极小来源眉注，永远不让 AI 的总结冒充你的亲口表述。

### 5.4 色彩、字阶、图标与零说教纪律
严格延续 [09-视觉与主题.md](modules/09-视觉与主题.md) 与 `D-35` 纸面阅读风格（支持浅色纸面与深色暗纸双套 Token）：
- **界面自明，零说教文案**：严禁在界面中写解释产品理念的副标题或提醒语（如“建议 1 项主线 · 护住当天硬骨头”、“足够小且清晰”、“绝不画密格”、“绝不改写正文”等）。改用以下克制的视觉线索直接引导视线与心智：
  - **克制图标与留白**：分组标题一律用纯文字加宽留白呈现，不堆砌装饰性小图标；全链路零 emoji；
  - **语义容量刻度微点（Capacity Dots）**：在早/下午/晚槽位右端用极细圆点（实心已占 / 空心余位 / 暖琥珀超容）无声传达推荐容积，无需任何解释文字；
  - **视线聚焦层级**：同一视野仅允许 1 处强调色焦点（如上午主线左侧 2px 静蓝竖边）；次要栏默认略降对比度，悬停即清晰；
  - **安心反馈靠实/虚线与可撤销回执**：未落盘草稿一律虚线区分，动作后给出一行可撤销收据，用确定性机制代替口号文案。
- **四档极简字阶**：主标题（仅幕布/页首使用）、正文（Logseq 原生阅读字号）、辅助眉注（来源/时间/状态）、微提示（快捷键/弱计数）。绝不在单屏内混用五六种字号。
- **四组低饱和语义色（色光只提示，绝不尖叫）**：
  1. **纸墨中性色**（米白/暗炭纸底 + 炭黑/暖灰墨字）：承载 95% 画面；
  2. **雾青 / 静蓝**（低饱和）：当前主线焦点、起飞跑道、恢复页直达入口；
  3. **暖砂 / 淡琥珀**（低饱和）：昨日遗留、超容提示、恢复页唯一卡点；
  4. **苍绿**（低饱和）：收尾后的对外一句话汇报与已验证小抄。
- **静音与零焦虑铁律**：
  - 严禁出现红色未读角标、闪烁提示、倒计时数字、进度百分比、自律打分或任何 emoji；
  - 动效仅用于表达真实状态迁移（如打字隐身淡出、逐段聚焦淡化），并完整尊重系统「减弱动态效果」设置；
  - 所有高频轻交互全程可只靠键盘完成，绝不强迫反复找鼠标。

### 5.5 典型界面如何体现「风格逻辑统一」
1. **桌面总览（无盒纸面、左重右轻）**：
   - 左列直接把早/下午/晚三段写在纸面上（无卡片套壳），右列候选栏默认降低对比退后一步，鼠标移入自然清晰；
   - 早间只露明确待办，前晚展开承诺原话与多项目方向，位置记忆不变、心智瞬间切换。
2. **纸面现场（心流优先、隐身框架）**：
   - 顶栏仅保留极素文字动作，敲字 1 秒后顶栏与外围全部淡出隐身，配合逐段聚焦把视线彻底收束在当前一段；
   - 自由记录区以极细横线融入正文底部（可一键弹为悬浮窗），点击「标记供 Agent 加工」静默进入整理队列；收尾后顶部浮出 2px 苍绿细线的「对外一句话汇报」。
3. **晚间安静回望室（100% 留我自己的想法）**：
   - 左侧极淡纯文字列出今日脚印参考（无边框、可点查原记录）；右侧大片空白纸面直接写自己的反思与体会，下方衔接无框「正在养的想法」时间线顺手补写；
   - Agent 默认完全闭嘴，绝不插话塞观点或做选择题。

## 6. Logseq 插件实现难度与真实技术可行性调研

基于对当前仓库 `apps/logseq-plugin/src/`（`focus-capsule.ts`、`overlay.ts`、`index.ts`、`native-editor.ts`）与 `packages/stage-runtime/` 的源码核查，这套表现系统**整体具备扎实落地能力**，但不同模块在 Logseq 宿主里的工程难度与边界明显不同：

| 模块 / UI 能力 | 实现难度 | 真实实现路径（基于仓库已验证底座） | 主要坑位与务实解法 |
| :--- | :--- | :--- | :--- |
| **日程模块（`本周 \| 今日 \| 明日` 无盒纸面）** | **低（直接可做）** | 渲染在我们完全自控的 `GlobalStageOverlay` / DSH 浮窗 / `/stage/app` 中，直接精简 `stage-runtime/src/renderer.ts` CSS，并在 `TimeEngine` 补齐 `tomorrowSlots` 快照（底层 `date` 已支持写明天） | 几乎无宿主限制；零破坏 Logseq 主界面风险 |
| **冷启动 3 页纯纸恢复 & 晚间纯自我手记室** | **低（直接可做）** | 同属我们自控的纯纸浮层或独立 `/stage/app` 视图；冷启动末页调 `logseq.Editor.editBlock(uuid)` 直达原行；晚间手记点保存调 `appendBlockInPage` 原样写入今日 Journal | 脚印聚合直接复用 `TimeHub` + `iCloud Inbox` + Logseq Journal 只读索引 |
| **抬头换气（专注期藏计时与小抄，悬停/按需浮现）** | **低（直接可做）** | 改造现有 `focus-capsule.ts`（已验证通过 `window.top.document` 挂顶栏与 `-webkit-app-region: no-drag`），专注态收为极细 2px 顶边线，悬停或快捷键展开时长与后台小抄 | 比当前常驻胶囊更轻，零额外风险 |
| **Block 级事务 Zoom-in + 精准回锚停笔行微亮** | **低–中（底座已通）** | Zoom-in 已有 `logseq.App.pushState("page", { name: rootUuid })`；定位编辑已有 `scrollToBlockInPage` + `editBlock`；微亮给 `window.top.document.querySelector('[blockid="..."]')` 加 1.5s CSS 动画 | Logseq 异步渲染目标块可能有 100–300ms 延迟，且必须遵守 `native-source-set.ts` 的防中文输入法（IME `composing`）抢焦点规则 |
| **600ms 打字自动隐身顶栏 + 逐段台灯聚焦** | **中（可行，需护选择器）** | 监听 `window.top.document` 键盘输入 1s 防抖给 `body` 挂 `tc-in-flow` 淡出 `.cp__header` 与侧栏；逐段聚焦靠 Chromium `:has()` 选择器让非当前编辑块淡化（`.ls-block:not(:has(.editor-wrapper))`） | Logseq 升级可能微调内部 DOM 类名；嵌套父块需精确排除含当前编辑子块的祖先节点，且须保证移回顶边或按 `Esc` 100% 恢复 |
| **「自由随记」原生块 + `Ctrl+.` 盲写 + 悬浮窗** | **页内/盲写：低**<br>**实时双向悬浮窗：中高** | `Ctrl+.` 在 `window.top.document` 挂极简输入条，回车调 `insertBlock` 写入当前页/块下的「自由随记」子块（极稳）。悬浮窗在 Logseq 内也是 `window.top.document` 里的 `position: fixed` 可拖拽浮层 | **两大边界**：① Logseq 插件内的浮层切出 Logseq 后不会跨应用置顶（跨全系统需独立窗口）；② 悬浮窗与页内多子块“逐字双向实时同步”易引发 `updateBlock` 光标跳动与并发覆盖，**务实解法是单向防抖写回（开悬浮窗时仅在悬浮窗写，停手 500ms 或关闭时一次性落回子块）** |
| **全局暖白宣纸色调** | **低（注意不抢主题）** | 我们自绘的浮层与侧栏默认读取 Logseq `--ls-primary-background-color` / `--ls-primary-text-color` 自然融合，不强行覆盖用户已安装的第三方 Logseq 主题 | 提供可选的极简静心纸面样式开关，避免样式冲突 |
