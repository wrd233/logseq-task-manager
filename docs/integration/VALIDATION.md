## 本轮验证的边界

实机验证属于首版集成 smoke，未以真实个人数据验收，也未重复长期 soak、真实 DeepSeek Gate、中文输入法组合事件、崩溃/断电故障注入或其他 Logseq/平台版本测试。自动测试覆盖冲突草稿；实机只验收无冲突的内外编辑与保存。

材料文件写入已有版本核对、历史备份、临时文件和读回检查，但普通文件系统 API 无法提供与任意外部程序之间的原子比较交换。材料目录与关联文件应避免通过符号链接指向 Graph。工作视图打开普通块不会写来源 id，重建索引后的普通块恢复仍有限。

独立多根工作区、PDF/图片/目录适配、外部材料进入 Kernel 冻结 Evidence，以及 DB Graph/移动端/其他桌面平台，均保留为需求树中的后续规划。
