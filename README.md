# 长文档 · Logseq 插件

把长文字放在独立 Markdown 文件中，让 Logseq 留下一条简短引用。当前为本机可试用的 0.1 原型，已载入 Logseq 0.10.15 文件 Graph；不是市场发布版。

## 日常操作

1. 在 Logseq 的块编辑框里正常粘贴。单次达到 **2000 字符或 30 个非空行**，默认静默收纳成 Markdown，不弹面板、不抢焦点。
2. 点击生成的 `📄 标题` 引用，文档在 **Logseq 左侧**打开；直接点击正文编辑，停下输入后自动保存。
3. 看完点 `×`。回找文档可用 Logseq 顶部的「长文档」入口，或面板中的「‹ 文档库」。文档库搜索包含全文，支持中文短词。

默认只有一条标题栏、正文和底部保存状态。`···` 菜单包含格式工具开关、外部编辑器、定位来源、撤销收纳。格式工具默认隐藏，Markdown 语法仍可直接输入。支持 ⌘S；拖动右边缘调整宽度，也可让分隔线获得焦点后用左右方向键调整。

本机目录：`/Users/wangrundong/Documents/Logseq长文档`，在 Graph 外。自动收纳开关、目录、阈值在 Logseq 的插件设置中调整。当前默认路径针对本机配置；换电脑请先改目录。目录应是真实的独立目录，不要使用指向 Graph 内的符号链接。更换目录不会自动搬迁已有文档。

「外部编辑器」使用 macOS 对 `.md` 的默认打开程序，不强制指定 VS Code。也可直接在 VS Code、Typora 等编辑器里打开目录中的文件；保存后，左栏会自动刷新。已实测 VS Code 保存同步；本机未安装 Typora。

## 撤销与内容保护

- 刚粘贴后，Logseq 原生撤销可移除这次粘贴，重做恢复同一引用。
- 稍后可用 `··· → 撤销收纳，恢复原文`，把**当时粘贴的原文**恢复到来源块。它不是把后来修改过的文档全文写回 Graph。
- 两种撤销都**不删除外部文件**。来源块已删、引用变化或重复时，不强行替换。
- 外部版本与当前编辑同时变化时，暂停覆盖，提供两条路：另存当前草稿继续编辑，或另存草稿后加载外部版本。副本可以从文档库找到。
- 编辑快照暂存在本机插件缓存；正式写入前保留上一版文件，并读回核对。缓存不可替代磁盘备份；错误提示未消失前不要卸载插件、清除缓存或关闭 Logseq。
- 原始文本与富文本捕获记录在 `.longdoc/<ID>.json`，历史文件在 `.longdoc/history/`。不自动删除、限额或清理历史，请将**整个目录连同隐藏子目录**纳入备份。

若插件停用，独立 `.md` 仍可用外部编辑器打开，但 `longdoc://` 短引用依赖插件。不要手动重命名 ID 文件或拆散 `.longdoc` 元数据。保存失败后的 `.pending` 文件、原始捕获记录也不会自动清除。

## 技术结构

- `src/core.js`：独立文件存储、索引、保存前版本比较、历史备份、原文恢复、全文检索。
- `src/desktop-io.js`：集中封装 Logseq 桌面内部文件桥接，不另启后台服务。
- `src/plugin.js`：原生粘贴接管、左侧面板、编辑草稿、外部更新、Graph 来源导航。
- Vditor 3.11.2 即时渲染模式；依赖资源随构建本地打包。Turndown/GFM 将外部富文本转换为 Markdown，DOMPurify 清理 HTML。
- 650ms 轮询当前打开文档，需要两次相同外部内容才刷新；输入与粘贴期间暂缓刷新。实际刷新时延受系统调度影响。
- 修改文件前比较完整正文，备份后再次比较，再以临时文件重命名替换。普通文件 API **没有跨进程原子比较并交换保证**，不能声称极端同时写入绝对无冲突。

## 已知边界

- 目前只在 macOS、Logseq 0.10.15 文件 Graph 上验证，使用了桌面内部 API 与布局节点；Logseq 升级可能需要适配。未验收 DB Graph、移动端、Windows。
- 编辑体验接近即时渲染 Markdown，不等同于 Typora。查看不会主动改写原文；一旦实际编辑，Vditor 可能规范化空行、表格对齐等 Markdown 格式。
- 有来源引用定位，但**未实现 Logseq 原生双向链接索引、原生全局搜索接入**。全文搜索目前在插件文档库中完成。
- 相对图片/附件路径、Logseq 宏/查询/块嵌入、复杂公式等不在这一版完整验收范围；不承诺自动收纳图片附件。文档内远程图片可能由渲染器请求原地址。
- 未完整验收中文输入法候选/组合过程、大体积文档、成千上万篇文档检索、多窗口同时使用、断电/崩溃、网络盘和系统权限撤回。文件历史目前无容量上限。
- 正常路径已实测。编辑位置在捕获期间变化或磁盘写入失败等异常，会保留文件/原始记录并提示，恢复尚未覆盖所有图形化操作。

## 开发与验证

```sh
npm ci --ignore-scripts
npm test
npm run build
```

本机 Homebrew 默认 Node 存在动态库问题，已使用 Node 20 验证：

```sh
PATH=/opt/homebrew/opt/node@20/bin:$PATH npm test
PATH=/opt/homebrew/opt/node@20/bin:$PATH npm run build
```

在 Logseq 插件页选择「手动载入插件」，选择本仓库根目录；修改后构建并重载此插件。不要覆盖或停用其他插件。

命令面板保留「长文档：创建独立验收页面」和「长文档：写入诊断记录」，日常 UI 不放测试按钮。诊断是按需快照，不是持续日志或累计验收记录。
