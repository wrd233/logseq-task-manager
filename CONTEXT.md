# Task Copilot Personal Operations

This context defines how Task Copilot turns bounded Logseq material into reviewable personal-work structures without replacing the user's text, Focus, or formal state authority.

## Language

**Grill Session**:
A temporary, bounded conversation that resolves material-specific uncertainties before a structure preview can be proposed. It is not a formal object or a questionnaire.
_Avoid_: Form, wizard state, second project

**Material**:
The bounded source facts and user statements available to one Grill Session, each retaining its evidence reference and classification.
_Avoid_: Prompt dump, whole Graph

**Uncertainty**:
A material-specific unresolved boundary, outcome, completion test, or classification decision that prevents a safe preview.
_Avoid_: Required field, missing form value

**Understanding Draft**:
The session-only separation of confirmed facts, Copilot inferences, and explicit unknowns at the current turn.
_Avoid_: Project summary, formal fact

**Structure Preview**:
The final readable arrangement proposed only after every critical Uncertainty and every Material disposition has a safe resolution.
_Avoid_: Commit result, saved project

**Formal Proposal**:
The existing reviewable authority boundary through which a Structure Preview may request Graph or domain changes.
_Avoid_: Grill answer, Agent output
